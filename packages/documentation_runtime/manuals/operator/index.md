# 運営・記録マニュアル (Operate Home)

大会の準備、試合の記録、結果の集計・共有、日常の部内戦、名簿管理までを網羅した、大会運営者・記録係・審判・指導者向けのマニュアルです。

---

## 📋 大会の準備と設定
1. **[大会の新規作成](create_tournament.md)**: 基本情報（大会名・日付・会場）の登録と新フローの入口
2. **[チーム・選手登録](team_registration.md)**: 形式選択（3/5/7人制・個人戦）、補欠、名簿連携
3. **[部門別ルール設定](category_rules.md)**: 【新設】部門ごとの試合時間・延長・判定・代表戦・リミットの一括設定
4. **[試合作成とオーダー設定](setup_match.md)**: 【新設】個別試合の作成、オーダー並び替え、相手サジェスト、赤白切り替え
5. **[選手名簿（マスタ）管理](master_management.md)**: 【新設】道場生登録、学年別表示、新年度の一括進級、ストレージ管理

## 🥋 試合当日の進行と記録
6. **[大会ホーム画面の見方](home_guide.md)**: 【新設】呼び出しバナー、部門フィルターチップ、検索、ソート、全開閉、自道場ハイライト
7. **[試合の記録（点数入力）](match.md)**: タイマー、得点、反則自動一本、延長、代表戦、コメント、ドック、音声通知
8. **[進行中の一括ルール変更](bulk_rule_edit.md)**: 【新設】進行遅延対策、未終了試合の試合時間・延長の一括短縮変更
9. **[チーム試合状況](team_match_status.md)**: 【新設】進行中/待機中/終了ステータス、コート・部門別スワイプ、ボトムシート展開
10. **[ドック＆フローティングパネル活用法](dock_guide.md)**: 【新設】スピードダイヤル、Googleマップ型3段階シート、背面操作可能UI

## 📊 結果の集計・出力・プログラム
11. **[成績管理と公式記録](official_record.md)**: 遠征・成績サマリー、LINE用コピー共有、対戦別スコアカード、部門別タブ、高コントラスト出力
12. **[順位表・戦績ランキング](standings.md)**: 【新設】日本伝統勝率表記（〇割〇分〇厘）、勝ち点、個人・チーム順位表
13. **[大会プログラム管理・手書きビューワー](program_management.md)**: 【新設】PDF/画像登録、OCR解析、共有ペン・個人ペン・蛍光ペン・個別消しゴム

## ⚔️ 部内戦・システム環境・監査
14. **[部内戦の4大モード運営・公式記録](bunaiksen.md)**: 【新設】個人戦即スタート、団体紅白戦、総当たりリーグ、無限戦勝ち残り、過去日付カレンダー
15. **[システム設定画面](settings.md)**: ☀️サンシャインモード（21:1）、サーマル冷却・省電力制御、音声、通知、道場同期
16. **[監査ログ（操作履歴）の確認](audit_log.md)**: 試合ID絞り込み、改ざん防止イベントソーシング
