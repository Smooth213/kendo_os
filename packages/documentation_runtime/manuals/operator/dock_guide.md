# ドック＆フローティングパネル活用法

画面右下に常駐する「フローティングドック」は、どの画面からでも1タップで大会プログラム、チーム試合状況、公式記録、設定などを瞬時に呼び出せる画期的なナビゲーションツールです。

## 1. ドックボタンの操作とスピードダイヤル展開 {#speed-dial}

- **初期状態**:
  - 画面右下に小さな丸い剣道アイコンがフローティング配置されています。
- **タップして展開**:
  - タップすると、周囲に **L字型アダプティブ配置** でスピードダイヤルアイコンがなめらかに展開されます。
  - **📄 プログラム**: 大会プログラム（トーナメント表）
  - **🥋 チーム状況**: 各チームの試合進行ステータス
  - **📊 公式記録**: 成績サマリーと全試合結果
  - **⚙️ 設定**: システム環境設定
- **再度タップで収納**:
  - ドックボタン（または背景の任意の場所）をタップすると、スマートにアイコンが収納されます。

## 2. Googleマップ型「フローティングボトムシート」 {#floating-sheet}

ドックから機能（プログラムやチーム状況など）を開くと、画面下に「Googleマップ型フローティングシート」が展開されます。

### 3段階の高さ調節（Drag & Snap）
シート上部のドラッグハンドルを指で上下に動かすことで、3つの状態にスムーズに切り替わります。
1. **最小化（Collapsed - 80px）**:
   - 画面最下部に細いバーとして待機。タイトルと要点のみ表示。
2. **中間（Half - 45%）**:
   - 画面の半分まで展開。下半分で情報を確認しながら、上半分で元の画面を広々と見通せます。
3. **全面（Expanded - 90%）**:
   - 画面のほぼ全体まで展開。じっくりとトーナメント表やスコアを読み込みたい場合に最適です。

## 3. 背面操作可能UI（最大のメリット） {#interactive-background}

このフローティングパネルの最大の特徴は、**「シートを開いた状態のままでも、背面の画面を直接タップして操作できる」** 点です。

- **最小化・中間展開時**:
  - 背面の試合記録画面でスコアを入力したり、大会ホームのタイムラインをスクロール・タップすることができます。
  - いちいちパネルを閉じる必要がないため、**「トーナメント表で次の対戦カードを見ながら、手元で点数を入れる」** といったマルチタスクが完全に実現します。
- **全面展開時**:
  - 閲覧に集中できるよう、背景へのタップは安全にブロックされます。

## 4. ボトムシートと全画面表示の切り替え {#fullscreen-toggle}

シート上部ヘッダーの **【⛶ 全画面アイコン】** をタップすると、通常の全画面ページへ切り替えることも可能です。
使い慣れた全画面モードと、機動力の高いフローティングシートを好みに応じて自由に使い分けられます。
