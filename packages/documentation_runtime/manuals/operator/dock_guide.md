# ドック＆フローティングパネル活用法

画面右下に常駐する「フローティングドック」は、どの画面からでも1タップで大会プログラム、チーム試合状況、サブタイマー、クイックメモなどを瞬時に呼び出せる画期的なマルチタスクツールです。
特に、**「シートを開いたまま手元の試合記録やスコア入力を継続できる（背面操作可能UI）」** 設計により、現場の作業効率を飛躍的に高めます。

```
+-------------------------------------------------------------------+
|  [戻る] 第1コート 第3試合                                          |
|                                                                   |
|   +-----------------------------------------------------------+   |
|   |         赤: 山田 太郎   [ 3 : 00 ]   白: 佐藤 次郎        |   |
|   +-----------------------------------------------------------+   |
|   |  [ メ ]  [ コ ]  [ ド ]      |      [ メ ]  [ コ ]  [ ド ]   |   |
|                                                                   |
|   ================== [ Googleマップ型可動シート ] ================= |
|   | ☰ チーム試合状況   [ ⛶ 全画面 ]                   [ ✕ 閉じる ] |
|   |-----------------------------------------------------------|   |
|   | 🔴 試合中: 3チーム   🟡 待機中: 5チーム                        |   |
|   | 東道場 A  (第1コート) - 準決勝 第3試合                         |   |
|   | 西少年団  (第2コート) - 準決勝 第4試合                         |   |
+---+-----------------------------------------------------------+---+
|                                                 [ (面) ドック ]   |
+-------------------------------------------------------------------+
```

## 1. ドックボタンの展開と全9大機能 {#speed-dial-and-features}

### 1.1 L字型スピードダイヤルの展開
画面右下に浮かぶ丸い「面アイコン（FAB）」をタップすると、周囲になめらかなアニメーションとともにスピードダイヤルアイコンが展開されます。

### 1.2 全9つの搭載機能リスト
各アイコンをタップすると、現在の画面を離れることなくボトムシートが展開されます。

1. **📄 プログラム (`Icons.menu_book_rounded`)**:
   - 大会プログラム（PDFや画像）を閲覧。
   - 手書きペンツールによる書き込みやピンチズーム・拡大表示に対応。
2. **🥋 試合状況 (`Icons.groups_rounded`)**:
   - 全チームの進行状況（試合中/待機中/終了）サマリーをリアルタイム確認。
3. **📊 対戦表 (`Icons.scoreboard_rounded`)**:
   - 大会全体の公式対戦表・成績サマリー・勝敗表を表示。
4. **🖌️ クイックメモ (`Icons.brush_rounded`)**:
   - 審判からの連絡事項や申し送り、緊急メモを手書き・テキストで即座に記録。
5. **⏱️ タイマー (`Icons.timer_rounded`)**:
   - 試合用タイマーとは独立した「ドック専用サブタイマー」。
   - 合議時間、ウォーミングアップ、休憩時間の計測に活用可能（プリセット2/3/4/5分）。
6. **📲 観戦QR (`Icons.qr_code_2_rounded`)**:
   - 保護者や観客にリアルタイム速報を共有するためのQRコードを画面上に大きく表示。
7. **🔔 お知らせ (`Icons.notifications_rounded`)**:
   - 本部からの全体連絡やコート変更アナウンス履歴（未読バッジ付き）。
8. **❓ ヘルプ (`Icons.help_outline_rounded`)**:
   - アプリの操作マニュアルをその場で検索・参照。
9. **⚙️ 設定 (`Icons.settings_rounded`)**:
   - 表示モードやハプティクス（振動）、確認ダイアログのON/OFF設定。

## 2. アイコンのジグル（Jiggle）並び替えカスタマイズ {#jiggle-reorder}

ドックのアイコンは、使いやすい順序にいつでも並び替えることができます。

1. **ジグルモードの起動**:
   - スピードダイヤル展開中、**任意のアイコンを長押し** します。
   - 軽い振動（ハプティクス）とともに「ジグル並び替えシート」が表示され、アイコンが揺れ始めます。
2. **ドラッグ＆ドロップ**:
   - よく使う機能（例: プログラムやタイマー）をドラッグして先頭付近へ移動します。
3. **保存**:
   - 【完了】をタップすると、設定した並び順が端末に記憶され、次回から自分専用の並びで展開されます。

## 3. Googleマップ型「可動ボトムシート」の操作 {#draggable-sheet}

ドックから機能を開くと、画面下部に可動式のフローティングボトムシートが展開されます。

### 3.1 3段階のスムーズな高さ調整（Drag & Snap）
シート上部のドラッグハンドルを上下にスワイプすることで、3つの高さに瞬時に切り替わります。

* **最小化（Collapsed / 0.25）**:
  - 下方向へ素早くフリックすると、シートが最小化または閉じられます。
* **中間展開（Half / 0.58）**:
  - 画面の下半分に展開。上半分で元の画面（試合記録や大会ホーム）を見通しながら、手元で情報を確認できます。
* **全開展開（Expanded / 0.95）**:
  - 画面のほぼ全体まで展開。プログラムの図面や多くのチームリストをじっくり確認したい場合に最適です。

### 3.2 全画面モードへの切り替え
シート右上ヘッダーの **【⛶ 全画面アイコン】** をタップすると、通常のフルスクリーンページへ瞬時に移行できます。

## 4. 背面操作可能UI（マルチタスクの実現） {#interactive-background}

Kendo OS のフローティングドックは、通常のモーダルダイアログと異なり、`OverlayEntry` 直接描画アーキテクチャを採用しています。

* **シートを開いたまま背面の操作が可能**:
  - 例えば、**「中間展開（Half）で大会プログラムやチーム状況を見ながら、背面の試合画面でスコア入力やタイマーの開始/停止を行う」** ことができます。
  - 画面をいちいち閉じたり開いたりする手間が一切ないため、1台のタブレットで本部進行と記録を兼務する現場で圧倒的な威力を発揮します。
