# 部内戦の4大モード運営・公式記録

道場内の稽古日や月例会、合宿、練習試合などで日常的に行われる「部内戦」を、驚くほどスピーディーに管理・記録できる専用機能です。
個人戦・紅白戦・総当たりリーグ戦に加え、部内稽古特有の「無限勝ち残り（待機列ループ）」を完全サポートしています。

```
+-------------------------------------------------------------------+
|  [戻る] 2026/10/24 部内戦   [📅 日付選択]  [👁️ 観戦]  [📊 成績]   |
+-------------------------------------------------------------------+
|  【👑 無限勝ち抜きリーダーボード】                                 |
|  現在の王座: 山田 太郎 (5連勝中 🔥)   最多連勝: 佐藤 次郎 (7連勝)  |
|  本数トップ: 高橋 三郎 (12本)                                     |
+-------------------------------------------------------------------+
|  [ 部内戦セットアップ (4大モード) ]                               |
|  [ 個人戦 (即開始) | 団体戦 (紅白戦) | リーグ戦 | 無限戦 (勝ち残り) ] |
|  ---------------------------------------------------------------  |
|  ルール: [ 2分一本勝負 ]  延長: [ 無制限 ]                         |
|  待機列 (8人):  [ 🔀 シャッフル ]                                 |
|  1. 赤: 山田 太郎   (試合中)                                      |
|  2. 白: 佐藤 次郎   (試合中)                                      |
|  3. 待機: 鈴木 一郎 (ドラッグ＆ドロップで並び替え可能 ↕️)           |
|  4. 待機: 田中 四郎                                               |
+-------------------------------------------------------------------+
|  [ ＋ クイック対戦を始める ]   [ 部内戦専用ドック ☰ ]              |
+-------------------------------------------------------------------+
```

## 1. 部内戦の4大セットアップモード {#setup-modes}

トップ画面の「部内戦をはじめる」またはホームの試合作成からセットアップ画面（`BunaiksenSetupScreen`）を開くと、4つのタブが用意されています。

### 1.1 個人戦（即スタート）
* **最短3秒で試合開始**:
  - 赤・白の選手名を入力（または道場生マスタからタップ選択）し、【試合開始】を押すだけで即座にスコアボード画面へ移行します。
  - その場で急遽決まった1対1の申し合い稽古に最適です。

### 1.2 団体戦（紅白戦）
* **道場生を赤組・白組に二分して対戦**:
  - 道場生マスタ一覧から選手をタップし、赤組（東軍）・白組（西軍）の先鋒〜大将へスムーズにドラッグ＆タップ配置できます。
  - 勝敗は通常の団体戦スコアボードで自動集計されます。

### 1.3 リーグ戦（総当たり星取表）
* **参加者を選ぶだけで全組み合わせを自動生成**:
  - 参加する選手（3名以上）にチェックを入れるだけで、重複のない総当たり対戦カードと星取表が一括自動生成されます。

### 1.4 無限戦（勝ち残り・無限マッチ）
部内稽古の華である「勝った者がコートに残り、挑戦者が次々と挑む」エンドレス対戦モードです。
* **待機列（Queue）の登録**:
  - 参加選手を一括選択して待機列へ投入します。
  - **先頭の2名（1番目・2番目）** が最初の試合カード（赤・白）として即時生成されます。
* **ドラッグ＆ドロップ並び替え ＆ シャッフル**:
  - `ReorderableListView` により、待機列の選手カードを指でドラッグして対戦順を自由に入れ替えられます。
  - **【🔀 シャッフル】** ボタンを押すと、待機順が瞬時にランダム化されます。
* **自動循環（ループ）システム**:
  - 試合が終了すると、**勝者はそのままコートに残り、敗者は自動的に待機列の最後尾へ回ります**。
  - 次の挑戦者が自動的に相手としてセットされ、間髪入れずに次の試合を開始できます。

## 2. 部内戦ルールの簡易設定 {#rule-settings}

セットアップ画面上部のルール設定カード（`BunaiksenRuleSettingsCard`）から、その日の稽古方針に合わせたルールを調整できます。
* **試合時間**: デフォルト2.0分（1分半や3分にもワンタップ変更可能）。
* **勝負形式**: 一本勝負 / 二本先取（三本勝負）の切り替え。
* **延長戦**: 延長なし（引き分け） / 時間制限あり / 時間無制限一本勝負。

## 3. 部内戦ホーム画面の機能と構成 {#home-screen}

部内戦進行中は、専用の部内戦ホーム（`BunaiksenHomeScreen`）で一元管理されます。

1. **ヘッダーコントロール**:
   - **📅 日付選択カレンダー**:
     - カレンダーアイコンをタップすると日付ピッカーが開き、過去の部内戦記録（試合データが存在する稽古日）を瞬時にロードして振り返ることができます。
   - **👁️ 観戦プレビュー**:
     - 目のアイコンをタップすると、道場の見学者や保護者がスマートフォンで見ている画面（`/bunaiksen-viewer-home`）を本部席からそのまま確認できます。
   - **📊 成績一覧**:
     - その日の公式記録（`/bunaiksen-record`）へジャンプします。
2. **👑 無限勝ち抜きリーダーボード (`BunaiksenLeaderboardCard`)**:
   - 無限戦が行われている場合、画面最上部にリアルタイムランキングカードが出現します。
   - **現在の王座（連続防衛中の選手と連勝数）**、**本日最多連勝記録者**、**通算取得本数トップ** が自動表彰され、道場生のモチベーションを高めます。
3. **対戦カード一覧とアコーディオン**:
   - 進行中の試合（赤色バッジ）が最上部に固定表示され、タップで即座に記録画面へ遷移します。
4. **【＋ クイック対戦を始める】シート**:
   - 稽古中に遅れて来た道場生同士の飛び入り対戦や、先生からの指名対戦を、ボトムシートから1手でタイムラインへ差し込めます。

## 4. 部内戦公式記録とデータ保護 {#official-record}

部内戦終了後は、公式記録画面（`/bunaiksen-record`）で本日の全対戦結果、勝敗マトリクス、個人成績ランキング（勝率・取得本数）を一覧確認できます。
* **Isarローカル保護**: 大会データと同様、電波の届かない道場地下や体育館でもローカルにミリ秒単位で完全記録されます。
* **年度履歴の蓄積**: 日付ごとに独立してデータが永続化されるため、昇級審査の参考資料や年度末の皆勤・最多勝表彰の集計データとして活用できます。
