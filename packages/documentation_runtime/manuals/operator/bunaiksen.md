# 部内戦の4大モード運営・公式記録

道場内の稽古日や月例会、強化合宿などで日常的に行われる「部内戦」を、驚くほどスピーディーに管理・記録できる専用機能です。

## 1. 部内戦の4大セットアップモード {#setup-modes}

トップ画面の「部内戦をはじめる」からセットアップ画面を開くと、用途に応じた4つのタブが用意されています。

1. **個人戦 (即スタート)**:
   - 赤・白の選手名を入力（または道場生マスタから選択）し、【試合開始】を押すだけでわずか3秒で試合が始まります。
2. **団体戦 (紅白戦)**:
   - 赤組・白組のチーム編成を行います。道場生マスタから選手をタップして先鋒〜大将へ配置し、紅白対抗戦を一括編成します。
3. **リーグ戦 (総当たり)**:
   - 参加する選手（またはチーム）を選択するだけで、全通りの対戦カード（星取表）を自動生成します。
4. **無限戦 (勝ち残り・無限マッチ)**:
   - 勝った選手がコートに残り、次々と現れる挑戦者と連続で対戦する、部内稽古特有の勝ち抜きモードです。連続勝利数などが自動記録されます。

## 2. 部内戦ルールの簡易設定 {#rule-card}

画面上部のルール設定カードから、部内戦用の特別ルールを素早く調整できます。
- 試合時間（例: 2分、1分半）
- 1本勝負 / 2本勝負
- 延長戦の有無や時間設定

## 3. 今日の部内戦ホーム画面 {#home-screen}

部内戦の進行中は、専用のホーム画面で一元管理されます。

- **リアルタイム・リーダーボード（順位表）**:
  - 本日の試合結果から、勝率・勝者数・取得本数の上位者が画面上部にリアルタイム表示されます。
- **クイックマッチ追加（ボトムシート）**:
  - 稽古の合間に飛び入りで試合を追加したい場合、画面下のボタンから即座に新しい個人戦を差し込めます。
- **過去の日付カレンダー切り替え**:
  - 画面上部のカレンダーアイコンから過去の日付を選ぶだけで、先週や先月の部内戦記録を瞬時に呼び出せます。
- **観客席プレビュー**:
  - 目のアイコンをタップすると、見学者や保護者が見ている画面（部内戦ビュアー）を本部の端末からそのまま確認できます。

## 4. 部内戦 公式記録 {#official-record}

部内戦終了後は、公式記録画面（`/bunaiksen-record`）で本日の全対戦結果、総合成績、勝敗マトリックスを確認・出力できます。
