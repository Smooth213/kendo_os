# 選手名簿（マスタ）管理

道場に所属する門下生・選手の名前、学年、段位、所属カテゴリを一元管理するデータベース機能です。
ここで選手を登録しておくと、大会のチーム編成や部内戦の組み合わせで名前を入力する手間がゼロになります。

## 1. 選手の登録と編集 {#register-player}

トップ画面の「選手名簿 (マスタ) 管理」から開きます。

1. **新規選手の追加**:
   - 画面下の【＋ 選手を追加】をタップ。
   - 選手氏名（ふりがな）、学年（幼年、小1〜小6、中1〜中3、高校、一般など）、段位・級位を入力して保存します。
2. **選手の編集**:
   - リスト内の選手カードをタップすると、登録情報の変更や所属の修正ができます。

## 2. 学年別・カテゴリ別のグルーピング表示 {#grouping-modes}

画面上部の切り替えタブで、道場生を目的別に素早く見渡せます。
- **学年順**: 低学年、高学年、中学生などの年齢順に整理して表示。
- **五十音順**: 氏名の読み仮名順で検索。
- **一括選択モード**: 複数の選手を選択して一括削除や所属変更を行うことができます。

## 3. 🌸 新年度の一括進級機能（大人気機能） {#bulk-promote}

毎年4月の新年度を迎えた際、全道場生の学年を1人ずつ手動で書き直す必要はありません。

1. 画面右上のメニュー（︙）から **【新年度の一括進級】** を選択します。
2. 確認ダイアログで「進級を実行する」を承認します。
3. **すべての選手の学年が自動的に「＋1学年」繰り上げられます**（例: 小2 ➔ 小3、中2 ➔ 中3）。
4. 卒業学年（小6、中3など）の選手は、次のステージ（中学、高校、OB）へ自動移行するか選択できます。

## 4. データとストレージの管理 {#storage-cleanup}

右上のメニューから、データのバックアップや端末キャッシュの整理、データの安全なエクスポートを行うことができます。
