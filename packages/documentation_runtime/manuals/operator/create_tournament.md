# 大会を作成する

新しく大会や錬成会を開催するための最初のステップです。
大会の基本情報を登録し、チーム登録・部門別ルール設定へと進みます。

## 画面の見方と入力項目 {#operate-create-steps}

大会の作成は、画面上部のステップバーに沿って進めます。

1. **大会名（必須）**: 
   - 「第10回 少年剣道錬成大会」のように入力します。
   - 観客向け画面や公式記録の表紙にも表示される正式名称です。
2. **開催日（必須）**:
   - カレンダーから大会の開催日を選択します（デフォルトは当日）。
3. **会場名（必須）**:
   - 「日本武道館」「市民体育館 第1競技場」などの会場名を入力します。
4. **大会の備考・注意事項（任意）**:
   - 申し合わせ事項や開会時間などを自由に入力できます。

## 保存と次のステップ {#operate-create-next}

すべての必須項目を入力したら、画面下部の **【基本情報を保存してチーム登録へ】** をタップします。

> 💡 **新しい大会作成フロー**
> 大会基本情報を保存すると、自動的に **「チーム・選手登録」** 画面へ進みます。
> その後、**「部門別ルール設定」** 画面で試合時間や延長戦などの細かなルールを設定します。

## 作成した大会の確認と修正 {#operate-create-edit}

- 作成した大会は、トップ画面の「今日の試合を作る・見る」または「過去の大会を見る」から確認できます。
- 日付や大会名の変更が必要な場合は、大会ホーム画面の設定メニューから修正できます。
