# 大会ホーム画面の見方

大会ホームは、大会の全試合の進行状況、呼び出し、コート別カード、コメント、ドック機能が集約された運営の中枢画面です。

## 1. 画面上部：呼び出しバナーと大会ヘッダー {#header-and-banner}

- **呼び出しバナー（Call Banner）**:
  - 現在コートで戦っている「進行中の試合」および次に控えている「待機中の試合」がリアルタイムに表示されます。
  - コート別の進行遅れや次の試合順をひと目で確認できます。
- **大会ヘッダーカード**:
  - 大会名、日付、会場、登録チーム数が表示されます。
- **QR共有ボタン**:
  - 画面右上のQRアイコンをタップすると、観客・保護者用URLおよびQRコードが表示され、現場のスマホへ即座に共有できます。

## 2. タイムラインコントロールバー {#control-bar}

試合リストのすぐ上にあるコントロールバーで、多彩な表示操作が可能です。

1. **🔍 検索トグル**:
   - チーム名、選手名、コート名、部門名を入力すると瞬時にリストが絞り込まれます（インクリメンタル検索）。
2. **⇅ 昇順 / 降順ソート**:
   - 部門別・試合順の並び順を切り替えます。
3. **📂 全開閉トグル**:
   - 画面内の全試合カードを「すべて展開」または「すべて折りたたみ」します。
4. **⚙️ 一括ルール編集ボタン**:
   - 未完了の複数試合の試合時間や延長設定をその場でまとめて変更できるシートを呼び出します（進行遅延対策）。

## 3. 部門別フィルターチップ（Filter Chips） {#category-chips}

コントロールバーの下に、大会に存在する部門（例: 「すべて」「小学生低学年」「中学生男子」など）がチップとして横並びで表示されます。
目的の部門をタップするだけで、その部門の試合のみに絞り込んで効率的に管理できます。

## 4. 試合タイムラインカードの見方 {#match-cards}

- **自道場チームのハイライト**:
  - 自道場のチームが出場する試合はアクセントカラーで強調表示され、見落としを防ぎます。
- **アコーディオン開閉**:
  - 団体戦のカードをタップすると、先鋒から大将までの各対戦状況が展開されます。
- **コメント吹き出し**:
  - 試合に投稿された審判連絡やメモが吹き出しアイコンで表示されます。
- **クイックアクション**:
  - 【記録開始】【結果確認】などのボタンから該当の試合画面へ直結します。

## 5. オフライン防衛バナー（体育館電波ゼロ時） {#offline-banner}

体育館のWi-Fiや電波が切断された場合、画面最上部に **「⚠️ 体育館オフライン運営モード：ローカルDB（Isar）へ即時保存中」** という黄色・オレンジの防衛バナーが表示されます。
画面を閉じずにそのまま操作を続けてください。データはローカルディスクに完全保護され、電波回復時に自動同期されます。

## 6. ドックボタン（右下のフローティングボタン） {#floating-dock}

画面右下に常駐するドックボタンをタップすると、大会プログラム（トーナメント表）やチーム試合状況、公式記録へいつでもジャンプできます。
