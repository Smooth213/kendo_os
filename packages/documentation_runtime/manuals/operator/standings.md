# 順位表・戦績ランキング（リーグ勝ち点・日本伝統勝率表記）

大会や錬成会（練習試合）、総当たりリーグ戦において、参加選手やチームの戦績（勝敗数、勝率、勝ち点、総取得本数）を自動集計し、リアルタイムのランキング順位表を表示する画面です。
剣道界の伝統に即した **「〇割〇分〇厘」** の勝率表記や、同点時の厳格なタイブレーク自動判定機能を備えています。

```
+-------------------------------------------------------------------+
|  [戻る] 成績・順位表                                [ (面) ドック ] |
+-------------------------------------------------------------------+
|  ⚠️ 【完全同点（タイ）警告】                                       |
|  2位: 佐藤 次郎 と 3位: 高橋 三郎 が同勝ち点・同勝敗・同本数です。   |
|  (順位確定には代表戦または抽選が必要です)                         |
+-------------------------------------------------------------------+
|  [ 🥇 1位 ]  山田 太郎                     [ 勝率: 10割 🔥 ]      |
|  5試合 | 5勝 0敗 0分 | 取得本数: 10本 | 勝ち点: 15.0点             |
|-------------------------------------------------------------------|
|  [ 🥈 2位 ]  佐藤 次郎                     [ 勝率: 8割 ]          |
|  5試合 | 4勝 1敗 0分 | 取得本数: 8本  | 勝ち点: 12.0点             |
|-------------------------------------------------------------------|
|  [ 🥉 3位 ]  高橋 三郎                     [ 勝率: 8割 ]          |
|  5試合 | 4勝 1敗 0分 | 取得本数: 8本  | 勝ち点: 12.0点             |
|-------------------------------------------------------------------|
|  [ 4位 ]    田中 四郎                     [ 勝率: 6割 ]          |
|  5試合 | 3勝 2敗 0分 | 取得本数: 5本  | 勝ち点: 9.0点              |
+-------------------------------------------------------------------+
```

## 1. 順位決定ロジック（4段階ソート優先順位） {#ranking-logic}

Kendo OS は公式競技規則に準拠し、以下の **4段階の厳格な優先順位** に基づいて自動的に順位を決定します。

| 優先度 | 判定基準 | 説明 |
| :---: | :--- | :--- |
| **第1優先** | **勝ち点（Match Points）** | リーグ設定で定義されたポイント（例: 勝ち3点、引き分け1点、負け0点）の合計。 |
| **第2優先** | **勝利数（Wins）** | 勝ち点が並んだ場合、純粋な勝利試合数が多い選手を上位とします。 |
| **第3優先** | **敗戦数（Losses）** | 勝利数が並んだ場合、負けた試合数が少ない選手を上位とします。 |
| **第4優先** | **総取得本数（Points Scored）** | 勝敗数が並んだ場合、獲得した一本（メ・コ・ド・ツ・反）の総数が多い選手を上位とします。 |

---

## 2. 完全同点（Tie）自動検出と警告バナー {#tie-alert}

すべての判定基準（勝ち点、勝利数、敗戦数、取得本数）が完全に一致する選手やチームが存在する場合、システムが自動的に **「完全同点（タイ）警告バナー」** を画面上部に表示します。
* 3者以上の三つ巴（同点グループ）にも完全対応。
* 決勝トーナメント進出枠の決定や入賞順位の確定にあたり、**「代表戦」や「抽選」の実施が必要であること** を運営者へ確実に注意喚起します。

---

## 3. 日本伝統の勝率表記（〇割〇分〇厘） {#traditional-win-rate}

剣道界で古くから親しまれている伝統的な勝率表記（三桁表示）に完全対応しています。

* **全勝**: `10割`（1.000）
* **全敗**: `0割`（.000）
* **端数表記**:
  - `8割5分7厘`（例: 7試合中6勝 ➔ .857）
  - `7割5分`（例: 4試合中3勝 ➔ .750、末尾の0厘はスマートに省略）

---

## 4. ランキングカードのUIデザインと表彰機能 {#card-ui}

一覧の各選手カードには、視覚的に優れた表彰デザインが施されています。

1. **金・銀・銅メダルアイコン**:
   - **1位**: ゴールドメダルバッジ（`military_tech` アイコン）
   - **2位**: シルバーメダルバッジ
   - **3位**: ブロンズメダルバッジ
   - **4位以降**: 円形アバター内に順位番号（4, 5, 6...）を表示
2. **クリーンな選手名**:
   - 選手マスタと自動連携し、所属チーム接頭辞（例:「東道場:山田」➔「山田」）を除去した美しい選手氏名を表示。
3. **詳細成績サマリー**:
   - カード下部に「試合数」「勝・負・分」「総取得本数」「合計勝ち点」がひと目で分かるよう整理されています。

---

## 5. 錬成会・総当たりリーグでの現場活用 {#field-usecases}

* **強化錬成会での即時フィードバック**:
  - 1日に多数の申し合い稽古を行う錬成会において、「本日もっとも勝率の高かった選手」「最多取得本数者」をその場で即座に割り出し、稽古終わりの全体表彰やミーティングの講評に直結させることができます。
* **リーグ戦の途中経過確認**:
  - リーグ戦の途中で順位表を開くことで、あと何本取れば予選を通過できるかの戦略立案に活用できます。
