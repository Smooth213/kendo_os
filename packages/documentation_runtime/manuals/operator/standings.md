# 順位表・戦績ランキング

大会および錬成会で、選手やチームの成績（勝敗数、勝率、勝ち点、総取得本数）を集計し、リアルタイムのランキング順位表を表示する画面です。

## 表示項目と特徴 {#ranking-items}

1. **日本伝統の勝率表記**:
   - 勝率は、剣道界で伝統的に親しまれている **「〇割〇分〇厘」**（例: 8割5分7厘、全勝は「10割」）の美しい表記形式で自動計算されます。
2. **集計基準**:
   - **試合数**: 行った全試合の総数
   - **勝・負・分**: 勝利数、敗戦数、引き分け数
   - **取得本数（得失点）**: 獲得した一本の総数
   - **勝ち点（Match Points）**: 大会設定に応じた勝ち点配分
3. **個人戦ランキングとチーム別成績**:
   - 選手マスタと連動し、所属チーム名を除去したクリーンな選手名で個人ごとの勝率・順位を自動算出します。

## 画面の開き方と活用方法 {#how-to-use}

- **アクセス方法**: 大会ホームのナビゲーションメニュー、または公式記録画面の戦績リンクから開きます。
- **錬成会での活用**: 
  - 1日に何十試合も行う錬成会（練習試合）において、「今日最も勝率の高かった選手・チームはどこか」を即座に可視化し、表彰やフィードバックに直結させることができます。
