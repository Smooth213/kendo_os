# 試合の記録（タイマー・得点・Undo・確定）

試合のタイマー計時と得点・反則をリアルタイムに記録する、大会運営で最も重要なメイン画面です。
押し間違えても直ちに安全に取り消せる「多段Undo保護」や、誤操作を防ぐ「長押し安全ガード」を備えています。

```
+-------------------------------------------------------------------+
|  [戻る] 第1コート 第3試合  [正面視点 / 逆サイド視点]   [ドック ☰]  |
+-------------------------------------------------------------------+
|               赤: 山田 太郎           白: 佐藤 次郎               |
|                                                                   |
|   +-----------------------------------------------------------+   |
|   |                  [ 3 : 00 ] 計時タイマー                  |   |
|   |         (タップ: 開始/一時停止 / 長押し: 時間修正)        |   |
|   +-----------------------------------------------------------+   |
|                                                                   |
|   [ メ (面) ]   [ コ (小手) ]       [ メ (面) ]   [ コ (小手) ]   |
|   [ ド (胴) ]   [ ツ (突き) ]       [ ド (胴) ]   [ ツ (突き) ]   |
|   [   ▲ 反則   ]   [ 判定 ]         [   ▲ 反則   ]   [ 判定 ]     |
|                                                                   |
|   +-----------------------------------------------------------+   |
|   | ⚡ [5秒カウントダウン] 記録:【赤・面】  [取り消す(Undo)]  |   |
|   +-----------------------------------------------------------+   |
|                                                                   |
|   [ 操作履歴ミニログ（直近3件タイムスタンプ） ]                    |
|   [ ↩️ 1つ前の操作を取り消す (Undo) ]                             |
+-------------------------------------------------------------------+
|              [ 🔴 試合終了 / 確定 (1.5秒長押し) ]                 |
+-------------------------------------------------------------------+
```

## 1. 画面構成と主要UI要素 {#match-screen-layout}

1. **上部ヘッダー & 視点反転トグル**:
   - **コート・試合情報**: コート名、試合順、現在の部門、対戦ポジション（先鋒〜大将）。
   - **視点反転ボタン (`Icons.swap_horiz_rounded`)**:
     - 中央上部のピル型トグル（「正面視点」/「逆サイド視点」）。
     - 本部・審判席と記録員席の物理的な向きが反対の場合、ワンタップで画面の赤・白配置を左右反転させ、視覚的な誤認をゼロにします。
   - **フローティングドックボタン**: 画面を離れずにプログラムやチーム状況、サブタイマーを呼び出せます。
2. **スコアボード & 選手表示**:
   - 赤（タスキ赤）と白（タスキ白）の選手氏名・所属チーム名。
   - 取得本数ランプ（メ、コ、ド、ツ、反）がリアルタイムに点灯。
3. **中央タイマーエリア (`TimerWidget`)**:
   - 残り試合時間を大きく表示。
4. **赤白打突・反則アクションパネル (`MatchScoreActionSection`)**:
   - 左右に独立配置された大型打突ボタンと反則ボタン。
5. **Undo・履歴コントロールセクション**:
   - 5秒限定の「スマートUndoフローティングバー」。
   - 直近3件の「操作履歴ミニログ」と常設の「1つ前の操作を取り消す」ボタン。
6. **最下部アクションバー (`MatchBottomActionSection`)**:
   - 「試合終了」「記録確定して次へ」ボタン。

## 2. タイマーの操作と色変化・時間修正 {#timer-operations}

### 2.1 開始と一時停止（タップ操作）
* **計時開始**:
  - 主審が「始め！」を宣告したら、タイマーエリアをタップします。
  - 計時が始まると、枠線と背景が **全面レッド背景（白文字）** へと劇的に切り替わり、遠目からでも計測中であることが一目で分かります。
* **中断（一時停止）**:
  - 主審が「やめ！」を宣告したら、タイマーを再度タップします。
  - タイマーが一時停止し、背景色が通常色（インディゴ枠線）に戻ります。

### 2.2 残り時間の直接修正（長押し操作）
時計係の押し遅れや合議中断により時間を微調整したい場合、**タイマーを長押し** します。
1. 「時間修正」ダイアログが表示されます。
2. 分（m）と秒（s）の数値を直接キーボード入力します。
3. 【更新】をタップすると、指定した残り時間へ即座に補正されます。

## 3. 得点・反則の記録手順 {#scoring-and-penalties}

### 3.1 有効打突（一本）の記録
主審・副審の旗が上がったら、該当する側の技ボタンをタップします。
* **【メ】（面）** / **【コ】（小手）** / **【ド】（胴）** / **【ツ】（突き）**
* タップと同時に「ハプティクス（振動）」と音声読み上げ・効果音で確実にフィードバックされます。
* スコアランプに取得した技の文字が点灯します。二本先取ルールの場合、2本目が記録されるとシステムが自動的に勝敗成立を判定します。

### 3.2 反則（Hansoku）と自動一本付与
* **反則の加算**: 【反則】ボタンをタップすると、反則回数（▲1）が点灯します。
* **自動一本判定（重要）**:
  - **同じ選手が2回目の反則を犯すと、システムが自動判定して相手選手へ「1本（反）」を即座に加算**します。
  - 反則カウンターはリセットされ、以降さらに反則が重なった場合も2回ごとに相手へ一本が付与されます。

### 3.3 判定（Hantei）と途中棄権（Fusen / Retirement）
* **判定**: ルールで判定が有効な場合、【判定】ボタンから赤・白の旗の本数（例: 赤2 - 白1）を入力して勝者を確定します。
* **途中棄権**: 負傷等のアクシデント時は、メニューから途中棄権を選択して不戦勝処理を行えます。

## 4. 押し間違いの即時救済（スマートUndo機能） {#smart-undo}

Kendo OS は緊迫した試合記録現場で焦ってボタンを間違えた場合でも、冷静に元通りにできる二重のUndo保護を備えています。

### 4.1 5秒スマートUndoフローティングバー
* 有効打突や反則ボタンを押した瞬間、**画面下部に5秒間カウントダウン付きのフローティングバーが自動出現**します。
* 「記録:【赤・面】」のように直前のアクション内容が表示され、右側の **【取り消す】** を押せば1タップで即座にキャンセルされます。
* 5秒経過するとバーは自然に消えるため、記録進行の邪魔になりません。

### 4.2 常設ミニログ ＆ 「1つ前の操作を取り消す」ボタン
* スマートUndoバーが消えた後でも、画面中央下の操作履歴ミニログに直近3件の履歴がタイムスタンプ付きで残っています。
* **【1つ前の操作を取り消す (Undo)】** をタップすることで、直前の記録を取り消すことができます。
* **Undo実行時はタイマーの一時停止状態がキープされる**ため、焦らずに正しい打突を入力し直せます。

## 5. 試合終了と記録の確定（長押し安全ガード） {#finish-and-approve}

試合時間が終了した際、または二本先取が決まったら、最下部のアクションボタンで終了・確定を行います。

### 5.1 誤タップ防止の安全仕様
* 誤って触れて試合が勝手に終わってしまう重大トラブルを防ぐため、**「1.5秒間の長押し」**（または設定で「素早くダブルタップ」）が必須となっています。
* 単にタップしただけではスナックバーで「長押し（またはダブルタップ）してください」と案内され、処理は実行されません。

### 5.2 試合終了から次の対戦への遷移
1. **試合終了**:
   - 勝敗成立時または時間終了時に【試合終了】を長押しします。
   - 引き分けルールかつ同点の場合は自動的に【延長戦】ボタンに変化し、タップすると延長時間タイマーが開始されます。
2. **記録確定（Approve）**:
   - 試合結果を確認し、【記録確定して次へ】を長押しします。
   - 団体戦の場合、自動的に次のポジション（次鋒 ➔ 中堅 ➔ 副将 ➔ 大将）へスムーズに画面が切り替わります。
   - 大将戦または代表戦が終了すると、対戦サマリーダイアログが表示され、チーム全体の勝敗結果を確認できます。

## 6. 体育館オフライン（電波ゼロ）保護 {#offline-resilience}

体育館内でWi-FiやLTE通信が完全に切断された場合でも、**絶対にブラウザをリロードしたりアプリを終了したりしないでください。**
* 入力されたすべての打突・反則・タイマーイベントは、端末ローカルの高速DB（Isar）へミリ秒単位で即座に永続化されています。
* 通信が戻った瞬間に、クラウド（Firebase）へバックグラウンドで自動同期されます。画面上に警告バナーが表示されていても、そのまま平常通り試合記録を継続してください。
