# 試合の記録（点数入力）

試合のタイマー計時と得点・反則をリアルタイムに記録する、大会運営で最も重要な画面です。
間違えてもすぐに取り消し（Undo）できるため、落ち着いて操作してください。

## 1. 画面の基本構成と役割 {#match-screen-layout}

- **上部ヘッダー**: コート名、試合順、現在の部門、大会プログラムへのドックボタン。
- **中央スコアボード**:
  - **赤（左） / 白（右）**: 選手名、所属チーム名、タスキの色。
  - **技ボタン**: 【面】【小手】【胴】【突き】
  - **判定・反則ボタン**: 【反則】【判定】
  - **得点表示**: 取得した技（「面」「小手」など）の文字ランプが点灯。
  - **中央タイマー**: 残り時間の表示、タップで【開始 / 一時停止】。
- **下部コントロールバー**:
  - 【↩️ Undo（取り消し）】: 直前の得点や操作を取り消し。
  - 【確定（長押し）】: 試合結果を確定して次の試合へ進む。
  - 【コメント】: タイムラインへのメモ・審判連絡の投稿。

## 2. 試合進行の標準的な操作手順 {#match-operation-steps}

1. **試合開始**:
   - 主審が「始め！」と宣告したら、中央のタイマーをタップして計時を開始します。
2. **有効打突（一本）の記録**:
   - 主審の旗が上がったら、該当する側の技ボタン（【面】【小手】【胴】【突き】）をタップします。
   - 音声読み上げや効果音、振動（ハプティクス）で記録されたことが確実にフィードバックされます。
   - 二本先取の場合、2本目を記録すると自動的に勝敗が成立します。
3. **反則（Hansoku）の記録**:
   - 反則ボタンをタップすると反則回数（▲1）が記録されます。
   - **反則が2回になると、システムが自動判定して相手選手へ「1本（反）」を加算**し、反則表示をリセットします。
4. **中断（やめ）**:
   - 主審が「やめ！」と言ったら、タイマーをタップして計時を止めます。

## 3. 延長戦（Encho）と判定・代表戦 {#overtime-and-daihyo}

- **延長戦**:
  - 時間内に勝敗が決まらず引き分けとなった場合、設定に応じて自動的に延長戦へ移行します。
  - 延長タイマーが作動し、どちらかが1本取った時点で試合終了（一本勝負）となります。
- **判定（Hantei）**:
  - 判定ありルールの場合は判定ボタンから旗の数（赤2-白1など）を記録して勝者を決定できます。
- **団体戦の代表戦（Daihyo）**:
  - チーム全体の勝者数・本数が同点の場合、代表戦ボタンから代表選手同士の一本勝負へ進みます。

## 4. 試合の確定操作 {#finish-match}

試合終了後、画面下の **【確定】ボタンを1.5秒間長押し** します。
誤タップによる誤確定を防ぐため長押し仕様になっています。確定すると自動的に次のポジション（次鋒、中堅…）または次の試合へ切り替わります。

## 5. タイムラインコメントとスライド操作 {#comments-and-slide}

画面下部のコメントエリアから、試合に関する連絡事項（「面紐が切れて中断」「判定合議中」など）を投稿できます。
- **コメントの編集・削除**: 投稿したコメントカードを **指で左へスライド（Slidable）** すると、「編集」「削除」ボタンが現れます。

## 6. 体育館オフライン（電波ゼロ）時の動作 {#offline-protection}

体育館内で通信が切断されても、**絶対に画面を閉じたりリロードしたりしないでください。**
アプリは端末ローカルディスク（Isar）に全操作ログを即座に書き込んでいます。そのまま点数入力を続けてください。電波が復旧した瞬間に、未送信データが自動的にクラウドへ同期されます。
