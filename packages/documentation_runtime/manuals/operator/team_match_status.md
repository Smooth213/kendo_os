# チーム試合状況

指導者・引率の先生・保護者・選手が、**「自分のチームが今どのコートで、何番目に試合なのか」「現在試合中なのか」** をひと目で把握できる専用ステータス画面です。

## 主な機能とメリット {#features}

- **リアルタイムの試合進行ステータス**:
  - 🔴 **試合中（Live）**: 現在コート上で対戦が行われているチーム
  - 🟡 **待機中（Waiting）**: 次、または数試合後にコート入場を控えているチーム
  - ⚪ **終了（Finished）**: 本日の全試合を終えたチーム
- **状態フィルター**:
  - 【すべて】: 全登録チームを一覧表示
  - 【試合中のみ】: 現在コート上で進行している熱戦のみを抽出
  - 【待機中のみ】: 次に招集・アップが必要なチームを抽出

## 画面の見方と操作 {#view-and-operation}

1. **画面の開き方**:
   - 画面右下の **「フローティングドック」** をタップし、【🥋 チーム状況】を選択します。
   - ボトムシートとして展開され、シート上部の全画面アイコンをタップすると全画面表示（`/court-status`）に切り替えられます。
2. **部門・コートのスワイプ切り替え**:
   - 画面を左右にスワイプ（または上部の部門タブをタップ）することで、「小学生の部」「中学生男子」「第1試合場」などのグループを素早く切り替えられます。
3. **チームカードの情報**:
   - チーム名、現在の試合順、対戦相手、現在のコート名が表示されます。
   - カードをタップすると、その試合のスコアボードまたは進行画面を直接確認できます。

## 現場での活用例 {#field-use-cases}

- **招集係・進行係**: 「第2コートの次の試合のチームがアップを始めているか」を待機中フィルターで確認。
- **指導者・監督**: 複数チームを率いている際に、離れた別コートのチームが試合に入った瞬間を即座に検知。
