# チーム試合状況と団体戦リアルタイム勝敗

指導者・監督・引率責任者・保護者・選手が、**「自チームが今どのコートで、何番目に試合なのか」「対戦チームとの勝者数・本数差はどうなっているか」** をひと目で把握できる専用ダッシュボードです。
チームの招集準備や進行確認、団体戦の勝敗集計と代表戦の管理まで一括して行えます。

```
+-------------------------------------------------------------------+
|  [戻る] チーム試合状況   [全画面表示 ⤢]               [閉じる ✕]   |
+-------------------------------------------------------------------+
|  [🔴 試合中: 3チーム]   [🟡 待機中: 5チーム]   (リアルタイム集計)    |
|  [フィルター: すべて | 試合中のみ | 待機中のみ]                      |
|  [部門タブ: すべて | 小学生の部 | 中学生男子 | 第1試合場] (横スワイプ)  |
+-------------------------------------------------------------------+
|  [ チーム進捗カード ]                                              |
|  東道場 A チーム   [🔴 試合中]   第1コート 第3試合                  |
|  対戦: 西剣道少年団   (現在: 中堅戦進行中)                           |
|  [📲 BAND共有]   ➔ タップで「団体戦スコアボード」へ展開              |
+-------------------------------------------------------------------+
|  【団体戦スコアボード (星取表)】                                   |
|  東道場 A   vs   西剣道少年団                                     |
|  先鋒:  山田 (メメ)   -   (　) 佐藤  【東道場 1勝】                |
|  次鋒:  鈴木 (　)     -   (コ) 高橋  【西少年団 1勝】              |
|  中堅:  田中 (メ)     -   (　) 渡辺  (進行中)                      |
|  副将:  伊藤          -        小林                                |
|  大将:  渡部          -        加藤                                |
|  ---------------------------------------------------------------  |
|  合計:  2勝 (3本)     -   1勝 (1本)   [リアルタイム自動計算]       |

|           [ ⚔️ 代表戦を追加する (同点時に自動出現) ]                |
```

## 1. チーム試合状況画面の開き方と構成 {#access-and-layout}

### 1.1 画面へのアクセス
* **フローティングドックから（通常操作）**:
  - 画面右下の **「フローティングドック」** ボタンをタップし、【🥋 チーム状況】を選択します。
  - 試合記録画面や大会ホームの上にボトムシートとして重ねて展開されるため、現在の作業を中断せずに確認できます。
  - ボトムシート右上の **全画面アイコン（⤢）** をタップすると、全画面モード（`/court-status`）へ瞬時に切り替えられます。
* **大会ホームから**:
  - 大会ホーム画面のクイックハブメニューから直接全画面表示を開くことも可能です。

### 1.2 画面上部のサマリーバナーとフィルター
1. **進行状況サマリーバッジ**:
   - 🔴 **試合中（Live）**: 現在まさにコート上で試合を行っているチーム数。
   - 🟡 **待機中（Waiting）**: 次の試合、または招集・ウォーミングアップが必要なチーム数。
2. **状態フィルターチップ**:
   - 【すべて】: 大会にエントリーしている全チームを表示。
   - 【試合中のみ】: 現在進行中のコート・チームのみを抽出（白熱している試合を即座にチェック）。
   - 【待機中のみ】: まもなく出番となるチームを抽出（招集係や監督の進行管理に最適）。
3. **部門・コート切り替えタブ & 横スワイプ**:
   - 「小学生の部」「中学生男子」「第1試合場」などのグループタブをタップ、または **画面を左右にスワイプ** することで瞬時に切り替えられます。

## 2. チーム進捗カードの確認とアクション {#team-status-card}

一覧に表示される各チームのカードには、現場で必要な情報が集約されています。

* **表示情報**:
  - チーム名および所属部門名
  - 現在のステータスバッジ（🔴 試合中 / 🟡 待機中 / ⚪ 終了）
  - 割り当てコート名（例: 第2コート）と試合順番号
  - 対戦相手チーム名
  - 現在戦っているポジション（例:「中堅戦が進行中」「大将戦待機」など）
* **【BAND共有】ボタン**:
  - カード右上の共有ボタンをタップすると、自チームの現在の対戦状況やコート番号が記載されたテキストがコピー（またはBANDアプリ起動）され、保護者や遠方の関係者へワンタップで一斉連絡できます。
* **カードタップ時の遷移**:
  - **団体戦の場合**: 後述する **「団体戦スコアボード」** が開き、星取表とチーム勝敗を確認できます。
  - **個人戦・勝ち抜き戦の場合**: 対象の **「試合記録画面」** へ直接ジャンプします。

## 3. 団体戦スコアボード（星取表と勝敗自動計算） {#team-scoreboard}

団体戦カードをタップすると、公式試合記録と同じ形式の団体戦スコアボード（`/team-scoreboard/:groupName`）が表示されます。

### 3.1 先鋒〜大将の対戦マトリクス
* 各ポジション（先鋒・次鋒・中堅・副将・大将）の対戦選手名、取得本数（メ、コ、ド、ツ、反）、勝敗結果（〇、▲、引き分け）が星取表形式で一覧表示されます。
* 任意の行をタップすると、そのポジションの試合記録画面を開いて詳細を確認・修正できます。

### 3.2 勝者数（勝数）と取得本数（本数）の自動計算
テーブル最下部の **合計集計行** では、システムがリアルタイムに公式ルールに則った勝敗集計を行います。
* **赤チーム合計 vs 白チーム合計**:
  - 勝者数（例: 3勝 - 1勝）
  - 取得総本数（例: 5本 - 2本）
* 大将戦が終了した時点で、どちらのチームが勝利したかが自動判定されます。

## 4. 同点時の代表戦（Daihyo）自動発生フロー {#overtime-daihyo}

団体戦において大将戦終了時点で **「勝者数」「取得総本数」が完全に同点** となった場合、ルール設定（代表戦あり）に応じてシステムが自動判定します。

```
[大将戦終了：勝者数 2(3) - 2(3) で完全同点]
                   ▼
画面最下部に赤い【⚔️ 代表戦を追加する】ボタンが自動出現
                   ▼
タップして代表選手（赤・白）を選択
                   ▼
一本勝負の代表戦が即座に対戦枠へ追加され、試合画面へ移行
```

1. **代表戦追加ボタンの出現**:
   - 勝敗が決まらない場合、スコアボード最下部に **【代表戦を追加する】** ボタンが鮮やかに自動表示されます。
2. **代表選手の指定**:
   - ボタンをタップすると代表選手選出ダイアログが開き、登録選手一覧から代表者を選択します。
3. **一本勝負の記録**:
   - 代表戦はルール上「一本勝負（時間無制限または延長戦）」としてセットされ、一本取った側のチームがマッチ勝利となります。

## 5. 現場での活用ユースケース {#field-usecases}

| 役割 | 活用方法 |
| :--- | :--- |
| **大会本部・招集係** | 「待機中のみ」フィルターを使い、次の試合のチームが招集エリアに揃っているかを一括点検。 |
| **監督・指導者** | 離れた別コートで行われている自道場の他チームの戦況（勝数・本数差）を自席からリアルタイム確認。 |
| **保護者・応援席** | ドックからチーム状況を開き、あと何試合で我が子の出番になるかを正確に把握。 |
