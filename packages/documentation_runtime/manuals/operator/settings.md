# システム設定画面

端末の表示テーマ、直射日光対策、省電力サーマル制御、音声・触覚フィードバック、プッシュ通知、道場同期空間を最適にカスタマイズする画面です。

## 1. 表示と画面設定 {#display-settings}

1. **外観テーマ（Theme Mode）**:
   - **端末連動**: OS（iOS/Android/PC）のシステム設定に自動で追従します。
   - **ライト**: 明るい標準テーマ。
   - **ダーク**: 暗い会場や夜間に適した省電力・低刺激テーマ。
   - **☀️ サンシャインモード（超高コントラスト）**:
     - 体育館の直射日光や強い反射光、屋外会場でもクッキリ見えるように設計された最高視認性テーマ（純白×漆黒、コントラスト比21:1 WCAG AAA適合）。
2. **スリープ（画面消灯）防止**:
   - オンにすると、長時間の試合記録中や審判中に端末の画面が勝手に暗くなってロックされるのを防ぎます。
3. **省エネモード（背景アニメーション停止）**:
   - 背景の流体アニメーションを停止し、バッテリー消費を大幅に抑制します。
4. **🔋 サーマル冷却・省電力制御（自動安全ガード）**:
   - 猛暑の体育館での端末の熱暴走やバッテリー枯渇を完全自動で防止します。
   - 端末の発熱やバッテリー低下を検知すると、「⚡ 高速」から「🔋 エコ冷却」「🌿 極限省電力」へ自動移行します（計時精度は100%保証）。
   - サーマルバッジをタップすると、現在の冷却状態と安心解説シートを確認できます。

## 2. 音と振動・フィードバック {#audio-and-haptics}

1. **音声・サウンド設定**:
   - **OFF**: 無音で動作。
   - **効果音**: 「ピピッ」「カーン」などの打突音・合図音を再生。
   - **音声読み上げ（TTS）**: 「一本！ 赤・面！」「残り1分です」など、スコアや時間を合成音声でコール。
2. **マナーモード時も強制的に鳴らす**:
   - 体育館の騒音の中でも試合終了のブザーを確実に鳴らしたい場合に有効化します。
3. **触覚フィードバック (階層化ハプティクス)**:
   - タイマー操作（軽）、一本記録（強）、反則（2連打）、取り消し（長押し）など、操作内容に応じた異なる振動パターンで指先に伝達します（iOS/Androidアプリ版対応）。

## 3. プッシュ通知設定 {#push-notifications}

- **緊急連絡・本部アナウンスの通知**: 本部からの全体呼び出しや緊急連絡をポップアップ通知。
- **新着試合追加の通知**: タイムラインに新しい試合が追加された際に通知。
- **試合開始 / 試合結果通知**: 担当コートの試合が始まった際や結果確定時に通知。

## 4. 同期と道場ルーム設定 {#dojo-room-sync}

- **所属道場ルーム（organizationId）**:
  - クラウド上でデータを安全に分離・保管するための道場識別IDです。
  - QRコードの読み取りやルームコード入力により、別端末と即座に同一の道場空間へ同期接続できます。
