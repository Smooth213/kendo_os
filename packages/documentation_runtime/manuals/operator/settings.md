# システム設定画面

端末の表示テーマ、直射日光対策、文字サイズ、省電力サーマル制御、音声・触覚フィードバック、プッシュ通知、外部LIVE配信、データ保護ロックを最適にカスタマイズする画面です。

---

## 1. 表示と画面設定 {#display-settings}

### 1.1 外観テーマ（4大テーマモード）
* **端末連動**: OS（iOS / Android / macOS / Windows）のシステム設定に自動で追従します。
* **ライト**: 明るい標準テーマ。
* **ダーク**: 暗い会場や夜間に適した省電力・低刺激テーマ。
* **☀️ サンシャインモード（超高コントラスト）**:
  - 体育館の直射日光や強い窓際反射光、屋外会場でもクッキリ見えるように設計された最高視認性テーマです。
  - 純白（#FFFFFF）× 漆黒（#000000）のコントラスト比 21:1（WCAG AAA適合）を採用し、太陽光下でのスコア誤認をゼロにします。

### 1.2 文字サイズ設定（3段階スケーリング）
* **標準**: 通常のスマートフォン・タブレット向け最適サイズ。
* **大**: 視認性を1段階拡大。
* **特大**: 体育館の離れた審判席・本部席からの遠距離視認や、年長者・弱視の先生方の操作性を高める最大サイズです。

### 1.3 スリープ（画面消灯）防止
* **ON**: 長時間の試合記録中や審判中、タイマー計時中に画面が勝手に暗くなってスリープ・ロックされるのを防止します。
* 外部電源がない長時間の大会では、こまめなバッテリー残量の確認をおすすめします。

### 1.4 省エネモード（背景アニメーション停止）
* **ON**: 背景の流体アニメーション（Liquid Glass）を完全に停止し、GPU負荷とバッテリー消費を大幅に抑制します。

### 1.5 🔋 サーマル冷却・省電力制御（自動安全ガード）
猛暑の体育館における端末の熱暴走やバッテリー急減を完全自動で防止します。
* **3段階の自動適応**:
  - ⚡ **高速 (Normal)**: 通常動作
  - 🔋 **エコ冷却 (Cooling)**: 描画レート・背景負荷の抑制
  - 🌿 **極限省電力 (Ultra-Save)**: 最低限の描画で端末を冷却保護
* **時間精度100%保証**:
  - どのような冷却モード下でも、試合タイマーの計時精度（第502条 Clock Skew補正規約）は一切影響を受けず、常にミリ秒精度を保証します。
* **サーマルバッジ**:
  - タイル右側のバッジをタップすると、現在の発熱状態と詳細解説シートを確認できます。

## 2. 音と振動・フィードバック {#audio-and-haptics}

### 2.1 音声・サウンド設定
* **OFF**: 無音で動作。
* **効果音**: 試合開始、終了ブザー、打突合図音などの効果音を再生。
* **音声読み上げ（TTS）**: 「一本！ 赤・面！」「残り1分です」など、スコアや時間を合成音声でアナウンス。

### 2.2 マナーモード時も強制的に鳴らす
* **ON**: 端末がサイレント/マナーモードに設定されていても、試合終了ブザー等の重要サウンドをスピーカーから強制鳴動させます。体育館の喧騒の中でも合図を聞き逃しません。

### 2.3 触覚フィードバック（階層化ハプティクス）
操作内容に応じて指先に伝わる振動パターンが直感的に変化します。
* **タイマー操作**: 軽微なクリック感（軽）
* **一本取得**: 明確なインパクト（強）
* **反則判定**: 警告の2連続振動（2連）
* **取り消し（Undo）**: 長めのホールド振動（長）
* ※ 触覚バイブレーションは iOS / Android アプリ版で動作します（Webブラウザでは端末仕様により制限されます）。

## 3. プッシュ通知設定 (iPhone / iPad / Web対応) {#push-notifications}

大会運営の重要イベントをリアルタイムにプッシュ通知で受信できます。

1. **🚨 緊急連絡・本部アナウンスの通知**: 本部からの全体招集、コート変更、緊急呼び出しを即座にポップアップ。
2. **➕ 新着試合追加の通知**: 担当コートに新しい試合が追加された際に通知。
3. **▶️ 試合開始の通知**: 試合の計時が開始された瞬間に通知。
4. **🏆 試合結果・終了の通知**: 勝敗が決着しスコアが確定した際に通知。

> [!NOTE]
> **iPhone / iPad Safari（Web版）での受信手順**
> 1. Safariの共有ボタンから「ホーム画面に追加」を行ってPWAとして起動します。
> 2. 設定画面の各通知スイッチをオンにし、OSが表示する「通知の許可」を承諾してください。

## 4. 外部連携・LIVE配信（BAND設定） {#external-integration}

保護者や道場関係者へのリアルタイム情報配信を自動化します。

* **BANDグループ登録**:
  - 「低学年チーム」「高学年チーム」など、部門ごとに配信先BANDグループのURLを設定できます。
* **全端末自動同期**:
  - 登録されたBAND設定は、道場ID配下の全端末（記録員・監督端末）へクラウド経由で自動同期されます。
* **ワンタップ配信**:
  - 試合カードのBANDアイコンをタップするだけで、対戦カード情報を自動整形してクリップボードにコピーし、BANDアプリのLIVE配信画面を瞬時に立ち上げます。

---

## 5. ローカル保存とデータ保護 {#data-protection}

* **記録確定後の修正ロック (`isLocked`)**:
  - スイッチをオンにすると、一度確定した試合結果やスコアの編集操作がロックされます。
  - 記録員の誤タップによるスコア改変を防ぎ、ローカルに保管された試合記録の安全性を高めます。

---

## 6. Webアプリ版（他端末アクセス） {#web-app-qr}

* **Webアプリ版 QRコード**:
  - タイルをタップすると、他端末からkendo_os本体を開くための専用QRコードダイアログ（`WebAppQrDialog`）が表示されます。
  - 観客用閲覧モードではなく、**操作用アプリ本体を別のタブレットやPCで即座に起動したい場合**にカメラでスキャンして利用します。

---

## 7. フローティングドック連携 {#dock-integration}

試合記録画面やトーナメント進行画面の右下に常駐するフローティングドックから「⚙️ 設定」をタップすると、可動ボトムシートとして設定画面が開きます。
* 背面の試合状況を見ながら、ワンタップでサンシャインモードや音量、通知設定を即座に変更できます。
* シート上部の全画面アイコン（⤢）をタップすると、本全画面設定ページ（`/settings`）へ移行します。
