# 成績管理と公式記録・PDF/CSV出力

全コート・全部門の全試合結果が集約され、大会の公式記録および遠征成績サマリーを出力・共有・保存する画面です。
全日本剣道連盟の公式書式に準拠した高品位な **A4 PDF出力** や、保護者連絡用の **LINE画像・テキストワンタップ共有**、データ分析用の **CSV出力** を備えています。

## 1. 遠征・戦績集計サマリーカード {#expedition-summary}

画面最上部には、自道場や参加チームの戦況を瞬時に把握・共有できる「遠征・戦績サマリー」が自動生成されます。

### 1.1 全体およびチーム別タブ集計
* **全体タブ**:
  - 道場全体の通算勝敗（例: 12勝3敗2分）、勝率、総取得本数を自動計算。
* **チーム別タブ**:
  - 「Aチーム」「Bチーム」など、エントリーチームごとの成績をワンタップで切り替え表示。
* **個人別戦績アコーディオン**:
  - タップして展開すると、選手ごとの勝敗数、取得した決まり手（面・小手・胴・突き・反則）の内訳を一覧確認できます。

### 1.2 📲 LINE用ワンタップテキストコピー
* サマリー右上の **【LINE用にコピー】** ボタンをタップすると、LINEグループや保護者連絡網へそのまま貼り付けられるよう、美しく整形されたテキスト（大会名、日付、チーム勝敗、個人成績）が一瞬でクリップボードにコピーされます。
* 遠征先から留守番の保護者や関係者へ、その日の活躍をわずか1秒で報告できます。

> 🛡️ **観客端末での自動非表示（Parity規約・公平性保証）**
> この「遠征成績サマリー」および「LINE用コピー」は、本部管理者および記録係の端末にのみ表示されます。観客や保護者が開く閲覧モードでは、大会速報の公平性を保つため自動的に非表示となります。

## 2. エクスポートアクションバーと3大出力形式 {#export-bar}

画面上部のエクスポートバーから、用途に応じた3種類の形式で公式記録を外部出力できます。

### 2.1 「全カテゴリを一括出力」トグルスイッチ
* **OFF（個別出力）**: 現在選択しているタブ（例: 小学生低学年の部）の記録のみを出力。
* **ON（一括出力）**: 大会に含まれるすべての部門（低学年、高学年、中学生等）の対戦結果を、1つのPDF/画像/CSVファイルにまとめて一括エクスポート。

### 2.2 3つの出力形式
1. **📄 PDF出力 (`Icons.print` / 赤色ボタン)**:
   - 全日本剣道連盟の公式大会記録フォーマットに則った **A4高コントラスト組版** でPDFを自動生成。
   - Webブラウザでは即座にダウンロード、タブレット・スマートフォンではAirPrint（直接印刷）や共有シート（ファイル保存・メール送信）が起動します。
   - ※ ブラウザのBlobリソース即時解放（メモリリーク防止）規約（第405条）に完全準拠しています。
2. **🖼️ 画像出力 (`Icons.ios_share` / LINEグリーンボタン)**:
   - LINEや各種SNSでそのまま送信しやすい高解像度PNG画像を生成。写真フォルダへの保存や共有シートからの直接送信が可能です。
3. **📊 CSV出力 (`Icons.table_chart` / インディゴボタン)**:
   - ExcelやGoogleスプレッドシートで開いて二次加工・年次統計に利用できるCSV生データを出力。

## 3. 対戦別公式スコアカードと検索機能 {#score-cards-and-search}

### 3.1 スコアカードの見方
* **ポジション別詳細**:
  - 先鋒から大将（および代表戦）までの選手名、取得本数、決まり手（メ、コ、ド、ツ、反、判）が正確に記録されます。
* **勝敗判定マーク**:
  - チーム全体の勝者数、総本数に基づき、勝利チーム側に「勝」マークが点灯します。

### 3.2 🔍 インクリメンタル検索バー
* ヘッダーの検索アイコンをタップして選手名や道場名を入力すると、該当する対戦カードがリアルタイムに絞り込まれ、目的の試合を瞬時に特定できます。

## 4. ドックからのボトムシート呼び出し {#dock-integration}

画面右下のフローティングドックボタンから【対戦表】を選択すると、試合記録中や大会ホームの画面上に **Googleマップ型可動ボトムシート** として公式記録を展開できます。
* シート上部の **【⛶ 全画面アイコン】** をタップすれば、いつでもフルスクリーン画面へ切り替えられます。
