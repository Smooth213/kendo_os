# 成績管理と公式記録

全コートの全対戦結果が集約され、大会の公式記録および遠征成績サマリーを出力・共有・保存する画面です。

## 1. 遠征・戦績集計サマリーカード {#expedition-summary}

画面最上部には、道場やチームの戦績を瞬時に把握・共有できる「成績サマリー」が自動生成されます。

- **全体 / チーム別切り替えタブ**:
  - 道場全体としての総合成績（勝率、勝者数、総本数）と、各チーム（Aチーム、Bチーム等）別の戦績をタブで素早く切り替えられます。
- **個人別戦績アコーディオン**:
  - タップして展開すると、各選手の勝敗数、取得した技の内訳（面〇本、小手〇本など）、引き分け数が一覧表示されます。
- **📲 LINE用ワンタップコピー機能**:
  - サマリー右上の **【LINE用にコピー】** ボタンをタップすると、保護者連絡網やLINEグループへ貼り付けるための美しい整形テキストが瞬時にクリップボードへコピーされます。
  - 会場から遠く離れた保護者へ、その日の戦績をわずか1秒で報告できます。

> 🛡️ **観客用画面での非表示（情報漏洩防止・Parity規約）**
> この「成績サマリー」および「LINE用コピー」は、本部管理者・記録係の端末にのみ表示されます。観客・保護者が開く画面では速報の公平性を保つため自動的に非表示となります。

## 2. 対戦別スコアテーブルカード {#score-tables}

各試合（団体戦、個人戦、勝ち抜き戦、リーグ戦）が美しいスコアテーブルカードとして表示されます。

- **ポジション別得失点**:
  - 先鋒から大将までの選手名、取得本数、決まり手（「メ」「コ」「ド」「ツ」「反」「判」）が完全記録されます。
- **チーム勝敗の自動判定**:
  - 勝者数、取得本数、代表戦の結果に基づき、勝利チーム側に「勝」マークが自動点灯します。

## 3. 部門別タブ切り替え {#category-tabs}

画面上部のタブから、「小学生低学年の部」「中学生の部」など各部門の記録を個別に切り替えて閲覧できます。

## 4. 高コントラスト出力と公式エクスポート {#export-actions}

画面上部のアクションバーから、用途に応じた出力が可能です。

1. **☀️ 高コントラスト出力（直射日光・白黒印刷用）**:
   - 背景を純白、文字を純黒（21:1コントラスト）へ瞬時に切り替え、屋外や日差しの強い会場でも最高視認性で印刷・閲覧できます。
2. **📄 PDF出力**:
   - 大会公式記録書としてPDFを生成します。Webブラウザでは自動ダウンロード、モバイル端末ではAirPrintや共有シートが起動します。
3. **📊 CSV出力**:
   - Excelやスプレッドシートで集計・加工するためのCSV形式で生データを保存します。

## 5. ドックからのボトムシート呼び出し {#dock-bottom-sheet}

画面右下のドックボタンから「公式記録」を選択することで、試合記録画面やタイムライン画面の上に **Googleマップ型ボトムシート** として重ねて展開できます。
