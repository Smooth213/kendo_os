# チーム・選手登録

大会に出場するチームおよび選手を登録・管理する画面です。
5人制・3人制・7人制・個人戦や、補欠選手の登録に対応しています。

## 1. 部門と試合形式の選択 {#select-format}

画面上部で、登録するチームの条件を設定します。

- **部門選択**: 「小学生低学年」「小学生高学年」「中学生男子」などの部門を選びます。
- **試合形式**: 
  - **5人制**（先鋒・次鋒・中堅・副将・大将）
  - **3人制**（先鋒・中堅・大将）
  - **7人制**（先鋒・次鋒・五将・中堅・三将・副将・大将）
  - **個人戦**（選手1名）
- **補欠の人数**: チームに所属する補欠選手の人数（0名〜複数名）を指定できます。

## 2. チームと選手の登録手順 {#register-steps}

1. **チーム名を入力**:
   - 学校名・道場名（例: 「武道館剣友会 A」）を入力します。
2. **各ポジションの選手を登録**:
   - 先鋒〜大将、および補欠の各枠をタップします。
   - **選手マスタから選択**: 事前に登録された道場生一覧からワンタップで選択できます。
   - **直接入力**: マスタにない選手はその場で名前を入力して決定します。
3. **【登録する】をタップ**:
   - チームが保存され、画面下部の「登録済みチーム一覧」に追加されます。
   - 続けて次のチームを連続して登録できます。

## 3. 登録済みチームの編集と削除 {#edit-team}

- 画面下部の登録済みチームカードをタップすると、選手オーダーを呼び出して修正できます。
- チームを削除したい場合は、対象カードのゴミ箱アイコンをタップします。

## 4. ルール設定への遷移 {#finish-to-rules}

すべてのチーム登録が終わったら、画面下部の **【登録を完了してルール設定へ進む】** をタップします。
独立した「部門別ルール設定」画面へ遷移し、部門ごとの試合時間などを設定します。
