# 部内戦専用ドックガイド（カレンダー・試合一覧・連勝・電卓）

部内戦モードの画面右下に常駐する「部内戦専用フローティングドック（`BunaiksenDockButton`）」は、日々の道場稽古や月例会を劇的に効率化するマルチツールです。
公式大会用の通常ドックとは異なり、**「カレンダー日付選択」「試合一覧」「連勝ランキング」「試合数・時間計算シミュレーター（電卓）」** など、道場稽古に特化した独自の機能を備えています。

```
+-------------------------------------------------------------------+
|  [戻る] 2026/10/24 部内戦                                         |
|                                                                   |
|   ================ [ 部内戦専用フローティングシート ] ============= |
|   | 📅 カレンダー日付選択   [ ⛶ 全画面 ]               [ ✕ 閉じる ] |
|   |-----------------------------------------------------------|   |
|   | 2026年 10月                                               |   |
|   | [10/10 (土)] [10/17 (土)] [10/24 (本日)]                  |   |
|   | ➔ タップで過去の部内戦記録を瞬時にロード                    |   |
+---+-----------------------------------------------------------+---+
|                     [ 🧮 電卓 ] [ 🏆 連勝 ] [ 📋 試合 ]  [ (面) ] |
+-------------------------------------------------------------------+
```

## 1. 通常大会ドックと部内戦専用ドックの決定的な違い {#dock-differences}

Kendo OS は「公式大会運営」と「日常の部内稽古」で求められる機能が根本的に異なるため、モードごとに最適化された2種類の独立したドックを提供しています。

| 項目 | 通常大会ドック (`FloatingProgramDockButton`) | 部内戦専用ドック (`BunaiksenDockButton`) |
| :--- | :--- | :--- |
| **主な使用シーン** | 週末の公式大会、トーナメント、広域錬成会 | 日常の道場稽古、月例会、強化合宿、紅白戦 |
| **閲覧ツール** | **📄 プログラム**: PDF/画像・手書きペン・ズーム | ❌ （部内戦では冊子プログラムは不要） |
| **進行状況** | **🥋 チーム状況**: 全コートのチーム進捗 | **📋 試合一覧**: 本日の部内戦カード・対戦結果 |
| **成績・集計** | **📊 対戦表**: 公式対戦マトリクス | **🏆 順位・連勝表**: 個人勝率ランキング・王座連勝記録 |
| **履歴管理** | 単一大会内の切り替え | **📅 カレンダー**: 過去の全稽古日記録をワンタップ呼出 |
| **シミュレーション** | ❌ | **🧮 電卓**: 稽古時間内の可能試合数・コート配分計算 |
| **共通ツール** | 🖌️ クイックメモ、⏱️ サブタイマー、📲 観戦QR、⚙️ 設定 | 🖌️ クイックメモ、⏱️ サブタイマー、📲 観戦QR、⚙️ 設定 |
| **並び替え操作** | シート上での順序編集 | 画面上で直接アイコンが揺れる **iOS風ジグル並び替え** |
| **ドッキング** | 右下フローティング | 画面端（左右）への **マグネット吸着・自動格納** 対応 |

## 2. 部内戦ドックの全8大機能リスト {#features-list}

ドックボタン（面アイコン）をタップすると、周囲にスピードダイヤルが展開されます。

1. **📋 試合一覧 (`Icons.list_alt_rounded`)**:
   - 本日行われたすべての部内戦カード、スコア、進行状況をボトムシートで一覧表示。
2. **🏆 順位・連勝表 (`Icons.emoji_events_rounded`)**:
   - 本日の個人勝率ランキングや、無限勝ち抜き戦の連勝防衛記録（王座）を即座に確認。
3. **📅 カレンダー (`Icons.calendar_month_rounded`)**:
   - 過去の部内戦開催日をカレンダー形式で一覧表示し、ワンタップで過去の記録へ切り替え。
4. **🧮 試合数計算機・電卓 (`Icons.calculate_rounded`)**:
   - 「稽古の残り時間（例: 45分）」「参加人数」「試合時間」を入力すると、何試合消化できるか、何コートに分ければ時間内に終わるかを自動試算。
5. **🖌️ クイックメモ (`Icons.brush_rounded`)**:
   - 師範・指導者からの指導講評や注意点を手書きキャンバスまたはテキストで即時記録。
6. **⏱️ サブタイマー (`Icons.timer_rounded`)**:
   - 試合計時とは別に、基本打ちや回り稽古、休憩時間をカウントダウン（2/3/4/5分プリセット）。
7. **📲 観戦QR (`Icons.qr_code_2_rounded`)**:
   - 見学中の保護者へ速報URLを共有するための大型QRコードを表示。
8. **⚙️ 設定 (`Icons.settings_rounded`)**:
   - 表示テーマや効果音・振動設定を調整。

## 3. 直感的な画面上ジグル（Jiggle）並び替え {#interactive-jiggle}

部内戦ドックは、スマートフォンでおなじみの「アイコンが直接揺れて並び替える」直感的なインタラクションを採用しています。

1. **ジグルモードの開始**:
   - ドックを展開後、**いずれかのアイコンを指で長押し** します。
   - 心地よい振動とともにすべてのアイコンが小刻みに揺れ始め（ジグル状態）、編集モードに入ります。
2. **ドラッグ＆ドロップ**:
   - 最もよく使う機能（例: カレンダーや電卓）をドラッグして、押しやすい位置のスロットへ移動します。
3. **完了と記憶**:
   - 画面の余白またはドック中心ボタンをタップすると編集が終了し、新しい配置が端末に自動保存されます。

## 4. 左右マグネット吸着・自動格納（Docked） {#magnet-docking}

部内戦の記録中、ボタンが画面の文字と重なって邪魔にならないよう、スマートな収納機能を備えています。

* **画面端へのドラッグ**:
  - ドックボタンを画面の左端または右端へドラッグすると、自動的に「細いタブ（幅20px）」として壁面に吸着・格納されます。
* **ワンタップで復帰**:
  - 格納されたタブをタップするだけで、元の円形ボタンへスムーズに飛び出し、即座に機能を利用できます。

---

## 5. Googleマップ型・背面操作可能UI {#interactive-background}

通常ドックと同様、OverlayEntry による背面操作可能アーキテクチャを採用しています。
* **シートを開いたまま部内戦を記録**:
  - 中間展開（Half）で「順位・連勝表」や「試合一覧」を見ながら、背面のスコアボードを直接タップして点数を記録できます。
