# 試合作成・オーダー編成（新フロー）

新しい対戦カードを作成し、相手チームの指定やポジションごとの選手オーダーを編成する画面です。
大会ホームの **【＋ 試合作成】** ボタンから開始します。

---

## 1. 試合作成フォーマット設定（ステップ ❶・❷） {#format-steps}

### ページ 1：部門と自チームの選択
1. **部門の絞り込み**:
   - 大カテゴリ（小学生・中学生など）および小カテゴリ（低学年・男子など）を選択します。
2. **出場する自チームの選択**:
   - 事前に登録したチーム一覧カードから、今回の試合に出場する自チームをタップして選択します。
   - ※ チームを選択すると、**前回同じチームが出場した「試合場（コート番号）」と「試合順（＋1試合）」が自動で引き継がれ補完入力**されます。
3. **【次へ進む】** をタップします。

---

### ページ 2：試合場・試合メモ・ルール設定
1. **試合場（コート）と試合順**:
   - 「第1試合場 第3試合」のように入力します（プリセットチップで簡単入力）。
2. **試合メモ（アドバンスド・ルール連動）**:
   - 「1回戦」「2回戦」「準決勝」「決勝」などの試合メモを入力します。
   - ※ 「準決勝」「決勝」と入力すると、事前に設定したアドバンスド・ルール（時間延長や延長無制限）が自動適用されます。
3. **対戦ルールの微調整**:
   - 必要に応じて試合時間や延長戦、勝点などの個別設定を微調整できます。
4. **【次へ進む】** をタップしてオーダー編成画面へ進みます。

---

## 2. オーダー編成と相手チーム設定 (`OrderSetupScreen`) {#order-setup}

対戦カードごとの選手配置と、相手チームの情報を編成します。

### ① 赤白タスキの選択
- 画面上部の **【赤 / 白 スイッチ】** をタップすると、自チームが「赤（先攻・上段）」か「白（後攻・下段）」かをワンタップで切り替えられます。

### ② 相手チーム名の入力
- 対戦相手の学校名・道場名を入力します。過去に入力した相手チーム名がサジェスト表示され、履歴からワンタップで選択できます。

### ③ 基本オーダーの呼び出しと記憶
- **【基本オーダーを呼び出し】**: チーム登録時に設定した基本オーダー（先鋒〜大将）をワンタップで一括配置します。
- **【現在のオーダーを基本オーダーとして記憶】**: 当日のメンバー変更を、今後の基本オーダーとして更新保存できます。

### ④ ポジション別スロット（先鋒〜大将）
- **自チーム選手**:
  - スロットをタップして選手マスタから交代選手を選択できます。
  - スロットをドラッグ＆ドロップすることで、**選手の配置順を直感的にスワップ（入れ替え）** できます。
- **相手チーム選手**:
  - 相手選手の名前を直接手入力できます（空欄でも可）。
  - **【欠員】ボタン**: 相手チームが4名以下など欠員がいる場合、枠横の【欠員】ボタンを押すとワンタップで「欠員」がセットされ、不戦勝（一本勝ち扱い）となります。

### ⑤ 枠の追加
- 6人制以上の変則団体の場合は、下部の **【枠を追加】** ボタンでスロットを増設できます。

---

## 3. オーダーの確定と試合開始 {#confirm-and-proceed}

画面下部の **【オーダーを確定して試合一覧へ】** をタップします。
- 作成された対戦カードが大会ホームのタイムラインへ追加されます。
- そのまま即座に試合記録画面へ入ることも、大会ホームで全体の進行状況を確認してから開始することも可能です。
