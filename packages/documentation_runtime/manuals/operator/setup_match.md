# 試合作成とオーダー設定

新しい試合の形式（団体戦・個人戦・勝ち抜き戦・リーグ戦）を決め、選手オーダーや対戦カードを組み立てる画面です。

## 1. 試合形式の選択（ステップ1） {#step1-format}

大会ホームの【＋ 試合作成】から起動し、まず試合の形式を選択します。

- **団体戦（通常）**: 5人制（先鋒・次鋒・中堅・副将・大将）、3人制、7人制など。
- **個人戦**: 1対1の対戦。
- **勝ち抜き戦**: 勝者が連続して相手選手と戦う勝ち残り形式。
- **リーグ戦（総当たり）**: 複数チームまたは選手による総当たり対戦カードを一括自動生成。
- **錬成会モード**: 連続して何試合も行う練習試合用の形式。

## 2. 部門と試合場（コート）の指定 {#step2-court}

- **部門**: 事前に設定した部門ルール（試合時間や延長設定）が自動連動します。
- **試合場（コート）**: 「第1試合場」「第2試合場」などを入力・選択します。
- **試合順（コート内オーダー）**: 「第1試合」「第2試合」などの順序を指定します。

## 3. オーダー設定と対戦相手の指定（ステップ2） {#step3-order}

形式を選択して次へ進むと、オーダー設定画面（`OrderSetupScreen`）が展開されます。

1. **自チームの選手配置**:
   - 先鋒〜大将のスロットをタップして、登録済み選手やマスタから選手を配置します。
   - スロットを長押しして上下にドラッグすることで、**選手の並び順を直感的に入れ替え（Reorder）** できます。
2. **相手チーム名の入力と履歴サジェスト**:
   - 相手チーム名を入力します。過去に入力したチーム名がサジェストされるため、文字入力の手間を大幅に省けます。
3. **タスキの色（赤・白）切り替え**:
   - ワンタップで自チームの配置を「赤」または「白」に切り替えることができます。

## 4. 試合の保存と開始 {#save-and-start}

画面下の **【試合を作成する】** をタップすると、対戦カードが生成されて大会ホームのタイムラインに追加されます。
そのまま即座に試合記録画面へ入ることも、後から順番に実施することも可能です。
