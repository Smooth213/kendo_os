# 進行中の一括ルール変更

大会が進行する中で、全体の進行遅れや体育館の利用時間制限に直面した際、**未完了の複数試合のルールを一括で緊急変更**するための強力な機能です。

## 使用するシチュエーション {#use-cases}

- 「全コートで試合が押しており、17時までに会場を明け渡さなければならない」
- 「決勝トーナメント直前で、第3回戦以降の試合時間をすべて3分から2分に短縮したい」
- 「延長戦を無制限から1回区切り（判定あり）へ一括変更したい」

## 画面の呼び出し方 {#open-sheet}

1. 大会ホーム画面を開きます。
2. タイムライン上部のコントロールバーにある **【⚙️ 一括ルール編集】** アイコンをタップします。
3. 画面下部から「一括ルール変更シート」が展開されます。

## 操作手順 {#operation-steps}

1. **対象試合の絞り込みと選択**:
   - **部門フィルター**: 「すべて」「小学生の部」「中学生の部」などを選択。
   - **形式フィルター**: 「すべて」「団体戦」「個人戦」を選択。
   - **一括選択**: 条件に合致する未完了の試合をチェックボックスで選択（一括選択ボタンあり）。すでに終了・確定した試合は自動的に除外されるため安全です。
2. **変更ルールの指定**:
   - **試合時間**: 3分 ➔ 2分 などへ変更。
   - **延長ルール**: 延長なし、延長1回、延長時間（2分 ➔ 1分）などを調整。
   - **判定（Hantei）**: 引き分け時に判定を行うかを選択。
3. **一括適用の実行**:
   - シート下部の **【選択した〇件の試合に適用する】** をタップします。
   - 確認ダイアログで最終承認すると、対象の全試合の設定が瞬時に書き換えられます。

> ⚠️ **注意事項**
> - 現在コート上で進行中（試合中）の試合がある場合、その試合のタイマーが突然変わるのを防ぐため、原則として「次の試合」から適用されるよう配慮してください。
> - 一括変更の操作履歴はすべて「システム監査ログ」に改ざん防止イベントとして安全に記録されます。
