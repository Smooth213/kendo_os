# 進行中の一括ルール変更（緊急ルール調整）

大会進行中に全体の遅れや体育館の完全撤収時刻に直面した際、**未完了の複数試合のルールを一括で緊急変更**するための強力な機能です。
通常大会ホームおよび部内戦ホームの双方から呼び出すことができます。

---

## 1. 使用するシチュエーション {#use-cases}

- 「全コートで試合進行が押しており、17時までに会場を明け渡さなければならない」
- 「第3回戦以降の試合時間をすべて3分から2分（流し込み）に一括短縮したい」
- 「延長戦を無制限から1回区切り（引き分け・判定あり）へ一括変更したい」
- 「部内戦で残り時間が少なくなったため、1本勝負へ一斉に切り替えたい」

---

## 2. 画面の呼び出し方 {#open-sheet}

1. 大会ホーム（または部内戦ホーム）を開きます。
2. タイムライン上部のコントロールバーにある **【⚡ 一括ルール変更】** アイコンをタップします。
3. 画面下部から「ルール一括変更」ボトムシートが展開されます。

---

## 3. 操作手順（3ステップ） {#steps}

### STEP 1：対象試合の絞り込みと選択 (`TargetSelect`)
1. **部門フィルター**: 「すべて」「小学生の部」「中学生の部」などを選択して絞り込みます。
2. **形式フィルター**: 「すべて」「団体戦」「個人戦」などを選択します。
3. **対象試合の選択**:
   - 条件に合致する試合カードが一覧表示されます。
   - チェックボックスをタップして個別選択するか、**【全選択 / 全解除】** で一括指定します。
   - ※ すでに終了・確定した試合は自動的に除外されるため、過去の確定記録が壊れる心配はありません。

---

### STEP 2：新ルールの設定 (`RuleForm`)
- **ルール不一致警告バナー**: 選択した試合の中で異なるルール（例: 2分の試合と3分の試合）が混在している場合、上部に注意バナーが表示されます。
- **部門プリセットの読み込み**:
  - 事前に設定された部門ルール（本戦ルール、錬成会ルール等）からワンタップで設定を流し込めます。
- **手動での個別調整**:
  - **試合時間**: 1分〜5分（ランニングタイムのオン/オフ）
  - **勝負形式**: 三本勝負 / 一本勝負
  - **延長ルール**: 延長なし / 1回のみ / 無制限（サドンデス）、延長時間
  - **判定・代表戦**: 判定あり/なし、代表戦の有無・延長設定

---

### STEP 3：一括適用の実行 (`BottomBar`)
1. シート最下部の **【選択した〇件の試合に適用する】** ボタンをタップします。
2. 確認ダイアログが表示されます。内容を確認して承認すると、**対象の全試合の設定が瞬時に最新化**されます。

> ⚠️ **注意事項**  
> 現在コート上で進行中（試合記録中）の試合がある場合、その試合のタイマーが突然変わるのを防ぐため、原則として「次の試合」から適用されるよう対象試合の選択にご配慮ください。
> 一括ルールの変更履歴はすべて「システム監査ログ」に改ざん防止イベントとして安全に記録されます。
