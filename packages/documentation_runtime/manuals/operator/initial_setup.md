# 初期設定・道場ID接続・4つの利用権限

アプリ起動直後の初期設定、接続先となる「道場ID（組織キー）」の設定、および利用者の役割に応じた「4つの権限」について説明します。

---

## 1. 道場ID（ルームキー）の設定 {#dojo-room-setup}

他団体とデータが混ざらないよう、アプリ起動時に接続先の「道場ID」を設定します。
一度接続すると、その道場の選手名簿や過去の試合データがクラウドから自動で読み込まれます。

### 操作手順
1. 起動直後の「役割選択（初期）画面」中央にある **「接続中の道場ID (ルーム)」バー** の右端にある **【変更】** ボタンをタップします。
2. 画面下部に「道場ルームへの参加」ボトムシートが表示されます。
   - **QRコードスキャン**: カメラマークをタップして道場のQRコードを読み取ります。
   - **手動入力**: テキスト入力欄に英数字で道場コードを入力します。
3. **【接続開始】** をタップします。
   - ※ 既にクラウド上に存在する道場IDの場合は、安全のための確認ダイアログが表示されます。「合流する」を選択すると接続が完了します。

---

## 2. 4つの利用権限とセキュリティ（PINコード） {#user-roles}

Kendo OSでは、現場での誤操作や不正なデータ書き換えを防ぐため、端末ごとに4つの利用権限を設けています。

| 役割名（画面表示） | カラー | 必要PIN | 権限範囲 |
| :--- | :--- | :--- | :--- |
| **代表・管理者 (Admin)** | 🟣 パープル | `9999` | 全機能を使用可能。物理削除・キャッシュクリア等の最高特権。 |
| **監督・引率責任者 (Operator)** | 🟢 ティール | `2468` | 大会の新規作成、リーグ戦や錬成会等の試合追加、結果印刷が可能。 |
| **スコア・記録係 (Recorder)** | 🔵 インディゴ | `1357` | 記録席端末用。臨時の試合作成、スコア・タイマー入力が可能（大会全体の初期設定は制限）。 |
| **応援・保護者・選手 (Viewer)** | ⚪ ブルーグレー | **PIN不要** | 完全閲覧専用。スコアやタイマーをリアルタイム観戦。編集ボタンは一切非表示。 |

### 操作手順（ログイン）
1. 役割選択画面で、ご自身の担当する権限ボタンをタップします。
2. **Admin / Operator / Recorder** を選択した場合は、**PIN認証画面（テンキー）** が表示されます。
3. 各ロールに対応する **4桁のマスターPINコード** を入力します。4桁入力されると自動で照合され、トップ画面へ遷移します。
4. **Viewer** を選択した場合は、PIN入力なしで即座に観戦用トップ画面へ進みます。

---

## 3. データ保存のしくみ（二重化構造） {#data-sync}

- **通常時**: 入力されたスコアやタイマー情報は即座にクラウド（Firestore）に反映され、同時に手元の端末内（Isar内蔵DB）にも保存されます。
- **電波切断時（オフライン）**: 体育館の電波が切れた場合は自動で端末内保存に切り替わります。記録をそのまま継続でき、電波が復旧した瞬間に自動でクラウドへ合流同期されます。
