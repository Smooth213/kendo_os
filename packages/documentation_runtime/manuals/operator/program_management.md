# 大会プログラム管理・手書きビューワー

大会の進行表、トーナメント表、申し合わせ事項などのPDFや画像を登録し、手書きペンやメモをリアルタイムに共有・閲覧できる高度なビューワー機能です。

---

## 1. プログラムの登録と管理 {#program-management}

大会ホームのカード、またはフローティングドックの「📄 プログラム」アイコンからプログラム管理を開きます。

### 1.1 アップロード方法（3つの取込ルート）
右下の【＋ プログラムを追加】（FAB）をタップすると、追加ボトムシートが展開されます。

1. **📷 写真ライブラリから選ぶ (複数可)**:
   - 端末の写真アルバムから JPEG / PNG 画像を選択します。複数画像をまとめて選択可能です。
2. **📄 ファイルから選ぶ (複数可)**:
   - 端末内ストレージやクラウドドライブから PDF または 画像ファイルを選択します。
3. **📋 クリップボードから貼り付け**:
   - Webブラウザや他アプリでコピーした画像や画像URLから直接ワンタップで取り込みます。

### 1.2 ファイル並び替え＆自動ナンバリング
複数ファイルを選択した場合、アップロード前に「プレビュー＆並び替えダイアログ」が表示されます。

* **ドラッグ並び替え**: ファイルの並び順を直感的に入れ替えられます。
* **タイトル自動ナンバリング**: ベースタイトル（例: `午前の部 トーナメント`）を入力すると、自動的に `午前の部 トーナメント (1/3)`、`(2/3)`、`(3/3)` と連番が付与されます。
* **画像自動圧縮**: アップロード時に高画質を維持しながら自動軽量化され、通信量とメモリ消費を最適化します。

### 1.3 一括選択と一括削除
* **長押し選択**: プログラムカードを長押しすると「複数選択モード」へ移行します。
* **一括削除**: 不要になった複数のプログラムにチェックを入れ、ヘッダー右上のゴミ箱アイコンからまとめて削除できます。

## 2. プログラムビューワーの操作性（直交スクロール） {#viewer-navigation}

プログラムカードをタップすると、全画面ビューワー（`ProgramViewerScreen`）が起動します。

### 2.1 直交2軸ナビゲーション
* **縦スクロール（同一PDF内のページ移動）**:
  - 複数ページのPDFは、上下にスクロールしてスムーズにページをめくります。
* **横スワイプ（ファイル間の切り替え）**:
  - 左右のスワイプ操作で、別のプログラム（例: 進行表 ➔ 第1試合場 ➔ 第2試合場）へ瞬時に切り替えられます。

### 2.2 ピンチズーム排他制御（誤スワイプロック）
* **2本指ピンチズーム**:
  - トーナメント表の細かい名前や星取表を最大倍率まで拡大できます。
* **誤操作防止ロック**:
  - **拡大中（ズーム倍率 > 1.01）は、左右スワイプによるファイル切り替えが自動的に完全ロック**されます。拡大して手書きメモを記入している最中に、不意に別ファイルへスワイプしてしまうストレスを完全に防ぎます。

## 3. 手書きアノテーションツールバー {#drawing-tools}

画面上部のアクションバーにあるペンアイコン（✏️）をタップすると、手書き描画ツールバーが展開されます。

### 3.1 共有ペン vs 個人ペンの厳格な分離
Kendo OS の手書き機能は、権限と用途に応じて保存先が完全に分離されています。

| ペン種類 | ペン色 | 利用可能権限 | 同期方式・保存先 | 主な用途 |
| :--- | :--- | :--- | :--- | :--- |
| **📢 共有ペン** | **ピンク・イエロー** | Admin / Operator / Recorder（本部・記録係） | **Firestore リアルタイム同期** | 勝ち上がり赤線、コート変更、重要連絡（全端末に即時反映） |
| **👤 個人ペン** | **ブルー・ブラック** | 全員（Viewer・保護者含む） | **端末ローカル（Isar DB）保存** | 個人の勝敗メモ、注目選手チェック（他端末には一切非公開） |

### 3.2 多彩な描画ツール
1. **🖍️ 蛍光マーカー（半透明・乗算合成）**:
   - 下の文字や罫線を塗りつぶさずに、重要箇所を鮮やかにハイライトします。
2. **🧹 個別ストローク消しゴム**:
   - なぞった線だけをピンポイントで削除できます。
3. **↩️ Undo（1手戻す）**:
   - 書き間違えた線を直前の状態へ戻せます。
4. **🗑️ 全消去**:
   - 画面上の手書き線を一括消去します。
   - **保護ガード**: 観客（Viewer）端末では、運営本部が書いた共有ペンを誤って消去できないよう保護されています。

## 4. PDFテキスト全文検索 {#pdf-search}

画面上部の虫眼鏡アイコン（🔍）をタップすると、PDFテキスト検索バーが展開されます。

* **インクリメンタル検索**:
  - 選手名や所属道場名を入力すると、該当箇所がリアルタイムに黄色でハイライトされます。
* **マッチ件数＆前後ナビゲーション**:
  - 「1 / 5件」のようにマッチ総数が表示され、上/下矢印ボタンで次の候補へ素早くジャンプできます。

---

## 5. フローティングドック連携 {#dock-integration}

試合の記録中やスコアボード確認中でも、画面右下のフローティングドックから「📄 プログラム」をタップすれば、Googleマップ型の可動ボトムシート（`ProgramBottomSheet`）でプログラムを即座に確認できます。

* **クイック確認**:
  - シート上でPDFや画像の確認・ズームが可能です。
* **全画面移行**:
  - シート上部の全画面アイコン（⤢）をタップすると、手書きツールバーを備えた本全画面ビューワーへシームレスに切り替わります。
