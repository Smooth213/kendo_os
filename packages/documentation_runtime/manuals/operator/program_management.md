# 大会プログラム管理・手書きビューワー

大会の進行表、トーナメント表、申し合わせ事項などのPDFや画像を登録し、手書きペンやメモをリアルタイムに共有・閲覧できる高度なビューワー機能です。

## 1. プログラムの登録と管理 {#program-management}

大会ホームやドックから「プログラム管理」を開きます。

1. **ファイルのアップロード**:
   - 右下の【＋ プログラムを追加】をタップ。
   - **PDFファイル**（複数ページ対応）または **画像ファイル（JPEG / PNG）** を選択します。
   - タイトル（例: 「午前の部 トーナメント表」）を入力してアップロードします。
2. **OCR自動テキスト解析**:
   - アップロードされた画像・PDFから文字を自動抽出し、検索可能なインデックスをバックグラウンドで構築します。
3. **一括選択と一括削除**:
   - カードを長押しすると「複数選択モード」に入ります。
   - 不要になった複数のプログラムを選択し、ゴミ箱アイコンからまとめて一括削除できます。

## 2. プログラムビューワーの操作性（直交スクロール） {#viewer-navigation}

プログラムカードをタップすると、専用のビューワー画面が開きます。

- **縦スクロール（PDFページ間移動）**:
  - 同一PDF内の複数ページを、上下に滑らかにめくることができます。
- **横スワイプ（ファイル間移動）**:
  - 別のプログラムファイル（例: 進行表 ➔ 第1試合場トーナメント ➔ 第2試合場トーナメント）へ、左右のスワイプで瞬時に切り替えられます。
- **ピンチズーム（拡大・縮小）**:
  - 2本指で細かな文字やトーナメントの山を自在に拡大できます。
  - **誤操作防止ガード**: 画面を拡大している最中は横スワイプが自動的に無効化されるため、拡大観察中に突然別ファイルへ切り替わってしまうストレスがありません。

## 3. 手書きアノテーションツールバー {#drawing-tools}

画面上のペンアイコンをタップすると、多彩な手書き描画ツールバーが展開されます。

1. **共有ペン（ピンク・黄色）※本部・記録係専用**:
   - ここに書いた勝敗の赤線や勝ち上がりライン、重要連絡は、**クラウド（Firestore）経由で観客や審判の全端末へリアルタイムに同期**されます。
   - 掲示板に紙を貼りに行く手間がゼロになり、本部から会場全体へ一斉に最新進行を伝達できます。
2. **個人ペン（青・黒）※全員利用可能**:
   - 自分専用の手書きメモです。他の人の画面には一切表示されないため、個人的な勝敗予想やメモを自由に書き込めます。
3. **蛍光ペン（半透明・乗算合成）**:
   - 下の文字や罫線を隠さずに、ハイライトマーカーのように重要箇所を目立たせることができます。
4. **個別消しゴムツール**:
   - タップした近接した線だけをピンポイントで削除できます。全消去ボタンも用意されています。
   - **保護ガード**: 観客端末では、本部が書いた共有ペンを誤って消去できないよう保護されています。
5. **↩️ Undo（1手戻す）**:
   - 書き間違えた線を直前の状態へ戻せます。
