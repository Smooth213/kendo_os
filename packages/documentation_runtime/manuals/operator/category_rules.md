# 部門別ルール設定

大会内の各部門（例: 小学生低学年、中学生、一般など）ごとに、試合時間や延長戦、勝敗判定などの個別ルールを独立して定義・一括適用する画面です。
初期大会セットアップでは、チーム登録完了後に自動でこの画面へ進みます。

---

## 1. 画面の役割とメリット {#overview}

- **部門ごとの完全なルール独立化**:
  「小学生低学年は2分・延長なし・判定あり」「中学生は3分・延長2分・代表戦あり」など、年齢や部門に応じた柔軟な設定が可能です。
- **決勝・準決勝アドバンスド・ルール（自動特例）**:
  「準決勝」「決勝」などのキーワードを含む試合に対して、自動的に試合時間の延長や延長無制限を適用するスマート機能を備えています。
- **既存試合への一括適用（Bulk Apply）**:
  ルールを変更・保存した際、すでに作成されている未完了の該当試合にも設定を一括反映できます。

---

## 2. 設定できるルール項目 {#rule-items}

部門カードの **【編集】** をタップすると、詳細設定フォームが展開されます。

### ① 基本時間と勝負形式
- **試合時間**: 1分〜5分（0.5分刻み）
- **ランニングタイム（流し計時）**: 時計を止めずに流すかどうか（錬成会等で有効）
- **勝負形式**: 三本勝負 / 一本勝負

### ② 延長戦（Encho）と判定（Hantei）
- **延長戦の有無**: あり / なし
- **延長時間**: 1分〜5分
- **延長回数**: 無制限（サドンデス） / 1回のみ / 2回まで
- **判定**: 引き分け時に審判3名の旗判定を行うかどうか

### ③ 団体戦の代表戦（Daihyo）
- **代表戦の有無**: あり / なし
- **代表戦の勝負形式**: 一本勝負 / 三本勝負
- **代表戦の延長**: 延長無制限 / 判定あり

### ④ 決勝・準決勝アドバンスド・ルール（特例設定）
- **特別ルールの有効化**: スイッチをオンにすると、特定試合用の別ルールを定義できます。
- **対象キーワード**: `準決勝`, `決勝`, `final`, `3位決定` など
- 該当する試合名（例: 「男子団体 決勝」）が作成された際、**通常の3分から4分へ自動延長、延長無制限へ自動移行**します。

---

## 3. 既存試合への一括適用ダイアログ {#bulk-apply}

設定を変更して **【保存】** をタップすると、システムが該当部門の未完了試合を自動検知します。
- **「〇件の試合に新ルールを一括適用しますか？」** という確認ダイアログが表示されます。
- **【一括適用する】** を選ぶと、該当するすべての試合設定が瞬時に最新化されます。
- 個別に調整中の試合を残したい場合は **【この部門設定のみ保存】** を選びます。

---

## 4. 大会ホームへの移動 {#finish-to-home}

すべての部門ルールの設定が完了したら、画面下部の **【設定を完了して大会ホームへ】**（初期セットアップ時）をタップします。
これで大会の基本準備がすべて整い、試合の組み合わせ作成・記録を行う「大会ホーム」へ進みます。
