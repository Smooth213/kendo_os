# 部門別ルール設定

大会内の各部門（例: 小学生低学年、中学生、一般など）ごとに、試合時間や延長戦、勝敗判定などの個別ルールを独立して定義・一括適用する画面です。

## 画面の役割とメリット {#category-rules-overview}

- **部門ごとの完全なルール独立化**:
  「低学年は2分・延長なし・判定あり」「中学生は3分・延長2分・代表戦あり」など、年齢や部門に応じた柔軟な設定が可能です。
- **既存試合への一括適用（Bulk Apply）**:
  ルールを変更・保存した際、すでに作成されている未完了の該当試合にも設定を一括反映できます。

## 設定できるルール項目 {#rule-items}

部門カードの【編集】をタップすると、以下の詳細設定シートが展開されます。

1. **基本時間設定**:
   - **試合時間**: 1分〜5分（0.5分刻み）
   - **ランニングタイム（流し込み）**: タイマーを止めずに流すかどうか
   - **勝負形式**: 3本勝負 / 1本勝負
2. **引き分け時の延長戦（Encho）**:
   - **延長戦の有無**: あり / なし
   - **延長時間**: 1分〜5分
   - **延長回数**: 無制限 / 1回のみ / 2回まで
3. **判定（Hantei）と代表戦（Daihyo）**:
   - **主審・副審の判定**: あり / なし
   - **団体戦の代表戦**: 代表戦を行うかどうか、代表戦の試合時間・延長形式
4. **反則と一本リミット**:
   - **反則リミット**: 通常2回で相手に1本
   - **一本リミット**: 2本先取（または1本）

## 既存試合への一括適用ダイアログ {#bulk-apply-dialog}

設定を変更して【保存】をタップすると、システムが該当部門の未完了試合を自動検知します。
- **「〇件の試合に新ルールを一括適用しますか？」** という確認ダイアログが表示されます。
- 【一括適用する】を選ぶと、該当するすべての試合設定が瞬時に更新されます。
- 個別進行中の試合を崩したくない場合は【この部門のみ保存】を選びます。

## 大会ホームへの移動 {#finish-to-home}

すべての部門ルールの設定が完了したら、画面上部の戻るボタン、または画面下部のアクションから **「大会ホーム」** へ移動して試合を開始・管理します。
