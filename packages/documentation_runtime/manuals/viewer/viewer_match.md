# 試合画面の見方（リアルタイム速報）

現在行われている試合のスコア、残り時間、有効打突（一本）、反則、勝敗結果を、客席や自宅から手元のスマートフォンでリアルタイムに確認できる観客専用スコアボード画面です。

---

## 1. 縦横レイアウト自動変形（電光掲示板スタイル） {#responsive-layout}

スマートフォンやタブレットの向きに合わせて、画面レイアウトが自動的に最適化されます。

* **縦画面（Portrait）**:
  - 片手で持ちながら、選手名、残りタイマー、一本スロット、反則回数をバランスよく確認できます。
* **横画面（Landscape）**:
  - スマートフォンを横向きに傾けると、会場の大型電光掲示板のような **超大型スコアボードレイアウト** に自動変形します。離れた席からでもスコアが一目で視認できます。

---

## 2. リアルタイム・スコアボードの見方 {#scoreboard-view}

### 2.1 選手情報
* **赤（左） / 白（右）**:
  - 選手氏名（道場名プレフィックスをクレンジングした見やすい表記）とタスキの色が表示されます。

### 2.2 残り試合時間タイマー
* 中央に大きく表示され、審判の宣告に合わせて秒単位でリアルタイムに減算カウントされます。
* 本時間で引き分けとなり延長戦に入ると、画面中央に **「延長」** バッジが鮮やかに点灯します。

### 2.3 有効打突記号ランプ
選手が一本を取ると、スコアスロットに剣道連盟公式の打突記号ランプが鮮やかに点灯します。

| 記号 | 意味 | 表示色 |
| :---: | :--- | :--- |
| **メ** | 面（Men） | 赤または白 |
| **コ** | 小手（Kote） | 赤または白 |
| **ド** | 胴（Do） | 赤または白 |
| **ツ** | 突き（Tsuki） | 赤または白 |
| **反** | 相手の反則2回による一本（Hansoku） | 金色ハイライト |
| **判** | 判定勝ち（Hantei） | 通常表示 |
| **不** | 不戦勝（Fusen） | 通常表示 |

### 2.4 反則カウントランプ
* 選手が反則を犯すと、選手名の下に **「▲1」** インジケータが点灯します。
* 2回目の反則を犯すと、相手選手側に **「反」** の一本が自動加算されます。

### 2.5 勝敗成立と引き分け
* 試合が決着すると、勝者側のカードに金枠ハイライトと **「勝（WINNER）」** マークが点灯します。
* 引き分けとなった場合は、中央に **「DRAW」** バッジが表示されます。

---

## 3. 完全閲覧専用（ゼロ誤操作設計） {#read-only-protection}

観客席用画面は **完全な閲覧専用（Read-Only）** です。
画面のどこをタップしてもスコアが誤って加点されたり、タイマーが止まったりすることは絶対にありません。お子様連れの保護者でも安心してお手元の画面を見守っていただけます。

---

## 4. 観戦リンクのQRコード共有 {#qr-share}

画面右上のQRコードアイコン（📲）をタップすると、現在見ている大会・コートの観戦リンクQRコードが表示されます。
客席で隣の保護者や道場の仲間にQRコードを見せるだけで、相手のスマホにも即座に同じスコアボード画面を開かせることができます。

---

## 5. 表示が止まった・更新されない場合 {#freeze-handling}

体育館内の混雑や電波の瞬断により、タイマーや数字の更新が一瞬止まる場合があります。
* **画面をリロードしたり閉じたりせず、そのまま数秒お待ちください。**
* 通信が繋がり次第、自動的に最新の正しいスコアへ一瞬で追いつきます。
