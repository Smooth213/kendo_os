# 試合画面の見方（リアルタイム速報）

現在行われている試合のスコア、残り時間、有効打突（一本）、反則を、客席や自宅からリアルタイムに確認できる画面です。

## 1. リアルタイム・スコアボードの見方 {#scoreboard-view}

- **赤（左） / 白（右）の選手情報**:
  - 選手氏名、所属チーム名、タスキの色が表示されます。
- **残り試合時間**:
  - 中央に大きく表示され、審判の「始め」「やめ」に合わせて秒単位で正確に動きます。
- **有効打突の表示**:
  - 選手が一本を取ると、「面」「小手」「胴」「突き」などの文字ランプが鮮やかに点灯します。
- **反則の回数**:
  - 反則を犯すと「▲1」が表示されます。2回目の反則で相手選手に「1本（反）」が自動加算されます。
- **延長戦（Encho）の表示**:
  - 本時間で引き分けとなり延長戦に入ると、画面が「延長戦」表示に切り替わります。
- **勝敗の成立**:
  - 試合が決着すると、勝者側に「勝」マークが点灯します。

## 2. タイムラインコメントの閲覧 {#comment-view}

画面下部には、本部やコート係から投稿されたメモや状況連絡（例:「判定合議中」「ただいま選手負傷手当のため一時中断」など）がリアルタイムに流れます。
※観客画面からは閲覧のみ可能で、誤って書き込んだり消去することはできません（安心安全仕様）。

## 3. ドックからの便利機能アクセス {#match-dock}

画面右下のドックボタンから、試合を見守りながら「大会プログラム」や「他コートのチーム状況」をいつでも呼び出せます。

## 4. 表示が止まった・更新されない場合 {#freeze-handling}

体育館内の混雑や電波の瞬断により、タイマーや数字の更新が一瞬止まる場合があります。
**画面をリロードしたり閉じたりせず、そのまま数秒お待ちください。** 通信が繋がり次第、自動的に最新の正しいスコアへ一瞬で同期されます。
