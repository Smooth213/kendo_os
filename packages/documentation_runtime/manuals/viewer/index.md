# 観客・閲覧マニュアル (Viewer Home)

観客、保護者、出場選手、指導者が、大会の進行状況やスコア、トーナメント表を客席や自宅から手元のスマートフォンでリアルタイムに確認するためのマニュアルです。
事前のアプリインストールや会員登録・ログインは一切不要です。

---

## 📱 観客向け機能ガイド
1. **[観客ホーム画面の見方](viewer_home.md)**: 【新設】進行中・待機中・終了試合リスト、部門別フィルター、本部一斉アナウンス
2. **[試合画面の見方（リアルタイム速報）](viewer_match.md)**: 秒単位のタイマー、一本打突ランプ、反則、延長戦、コメント閲覧
3. **[観客用チーム試合状況](viewer_team_match_status.md)**: 【新設】応援チームの現在のコート、次の試合順、待機状況
4. **[大会プログラム閲覧・個人メモ](viewer_program.md)**: 【新設】トーナメント表PDF/画像、自分専用の個人ペン（青・黒）、拡大ピンチズーム
5. **[観客用公式戦記録（全試合結果）](viewer_official_record.md)**: 【新設】全対戦確定スコアテーブル、☀️高コントラスト出力ボタン
6. **[観客用部内戦スコア確認](viewer_bunaiksen.md)**: 【新設】道場の部内戦タイムライン、本日の順位リーダーボード
7. **[団体戦スコアボードの見方](viewer_team_scoreboard.md)**: 勝者数・総本数、リード表示、代表戦のルール
8. **[勝ち抜き戦スコアボードの見方](viewer_kachinuki_scoreboard.md)**: 連勝数（〇人抜き）、残り人数、大将同士無制限一本勝負
