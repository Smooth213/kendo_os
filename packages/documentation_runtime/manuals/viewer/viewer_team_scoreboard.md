# 団体戦スコアボードの見方

5人制や3人制・7人制などの団体戦において、「チーム全体の勝敗」「勝者数」「取得本数」「現在どちらがリードしているか」を一目で把握できる専用スコアボードです。

## 1. 画面の見方 {#viewer-team-view}

- **対戦チーム名**: 赤・白両チームの学校名・道場名が表示されます。
- **ポジション別スコア**: 先鋒から大将までの各対戦者名、取得した技（メ、コ、ド、ツ、反、判）、勝敗マークが表示されます。
- **総合チームスコア**:
  - **勝者数**: チームで何勝を挙げているか（例: 2勝 vs 1勝）
  - **総本数**: チーム全体で獲得した一本の総数（例: 4本 vs 2本）
- **リード表示**: 現在リードしている側のスコアが明るくハイライトされます。

## 2. 勝敗の決まり方と代表戦 {#viewer-team-rule}

1. **勝者数の比較**: 個人戦の「勝った人数」が多いチームが勝利となります。
2. **取得本数の比較**: 勝者数が同数の場合、チーム全体の「総取得本数」が多いチームが勝利となります。
3. **代表戦（Daihyo）**:
   - 勝者数も取得本数も全く同点の場合、両チームから代表選手1名を選出して行う **「代表戦（1本勝負）」** がスコアボード最下部に追加表示されます。
