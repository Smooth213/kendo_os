# 観客ホーム画面の見方

スマートフォンのカメラで大会QRコードを読み取るだけで、アプリのインストールやアカウント登録・PIN入力なしに、全試合のリアルタイム速報やトーナメント表を客席から即座に閲覧できる画面です。

---

## 1. 接続方法（QRスキャン1秒アクセス） {#viewer-access}

1. 会場パンフレットや掲示板、大会本部に掲示されている **「観戦用QRコード」** をスマートフォンの標準カメラで読み取ります。
2. ブラウザが開き、自動的に完全匿名の閲覧セッションが確立されます。
3. **パスワードやログインは一切不要** です。

---

## 2. 画面上部：呼出バナーと大会情報 {#viewer-header}

### 2.1 招集・呼出バナー (`ViewerCallBanner`)
画面の最上部には、現在進行中の試合と次に控えている試合がリアルタイムに表示されます。

* 🔴 **進行中 (Live)**:
  - 各コートで現在対戦中のカード（コート番号、部門、選手名、ポジション）。
  - タップすると、秒単位で動くリアルタイムスコアボード画面へ即座に移動します。
* 🟡 **待機中 (Next)**:
  - 次、またはその次に招集される試合順。応援する選手の出番や準備状況を客席から把握できます。

### 2.2 3大クイックアクションボタン
バナー直下に配置された大型ボタンから、主要な画面へワンタップでアクセスできます。

1. **📄 プログラム**: 大会進行表やトーナメント表の閲覧（拡大ズーム＆自分専用メモペン対応）。
2. **📊 対戦表・スコア**: 大会公式記録・全対戦結果一覧（高コントラスト表示対応）。
3. **🏆 順位表**: リーグ戦の勝率・勝ち点ランキング。

### 2.3 大会情報カード
大会名、開催日、会場名、主催者、現在の総合進行ステータスが表示されます。

---

## 3. タイムライン検索と部門フィルター {#filter-and-search}

### 3.1 選手名・道場名インクリメンタル検索
虫眼鏡アイコン（🔍）をタップして検索バーを開き、選手名や道場名を入力すると、該当する試合カードが瞬時に絞り込まれます。

### 3.2 部門別フィルターチップス
画面上部のチップ（【すべて】【小学生低学年】【中学生男子】など）をタップすると、お目当ての部門の試合のみを表示できます。

### 3.3 試合順ソート＆全開閉トグル
* **ソート切り替え**: 試合進行順（第1試合 ➔ 第2試合）または最新順（逆順）に並び替えられます。
* **すべて展開 / 折りたたみ**: 団体戦のオーダーや詳細スコアを一括で展開・収納できます。

---

## 4. 本部一斉アナウンスポップアップ {#emergency-announce}

大会本部から「第1試合場 選手招集」「審判打ち合わせ」「落とし物連絡」などの全体アナウンスが送信されると、画面上部にリアルタイムでポップアップ通知が届きます。
館内放送が聞き取りにくい騒がしい体育館でも、重要連絡を確実に手元で確認できます。
