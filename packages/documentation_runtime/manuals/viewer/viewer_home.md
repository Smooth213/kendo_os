# 観客ホーム画面の見方

スマートフォンやタブレットでQRコードを読み取るだけで、アプリのインストールやログインなしに大会の全試合の進行状況や結果をリアルタイムで閲覧できる画面です。

## 1. 画面上部：大会情報と速報アナウンス {#viewer-header}

- **大会名・開催日・会場**:
  - 現在開催されている大会の基本情報が表示されます。
- **本部一斉アナウンス**:
  - 本部から「第1試合場、選手招集」「審判打ち合わせ」などの連絡が送信されると、画面上部にリアルタイムでポップアップ表示されます。

## 2. 進行中・待機中・終了の試合リスト {#match-sections}

画面は試合の状況ごとに見やすく整理されています。

- **🔴 進行中の試合（Live）**:
  - 現在各コートで対戦中のカードです。タップすると、秒単位で動くリアルタイムスコアボード画面へ移動します。
- **🟡 待機中の試合（Next）**:
  - 次、またはその次に控えている試合順です。応援する選手の出番が近づいているかを確認できます。
- **⚪ 終了した試合（Finished）**:
  - 本日終了した試合の結果と勝敗です。

## 3. 部門別・コート別の絞り込み {#filter-chips}

画面上部のフィルターチップをタップすることで、「小学生の部」「中学生男子」「第1試合場」など、お目当ての部門やコートの試合のみを素早く絞り込めます。

## 4. 便利なフローティングドックボタン {#viewer-dock}

画面右下の丸いドックボタンをタップすると、観客向けの便利機能がスピード展開します。
- **📄 プログラム**: 大会進行表やトーナメント表の閲覧（自分専用のメモ書き込みも可能）
- **🥋 チーム状況**: 応援している道場やチームの現在の対戦状況
- **📊 全試合スコア**: 大会の公式記録・全対戦結果一覧（高コントラスト表示対応）
