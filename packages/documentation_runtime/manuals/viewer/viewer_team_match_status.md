# 観客用チーム試合状況

保護者や応援の方々が、**「我が子のチームや所属道場が、いま第何試合場で戦っているか」「次はいつ出番なのか」** を客席やロビーから素早く確認できる画面です。

---

## 1. チーム試合状況画面の見方 {#how-to-view}

### 1.1 サマリー進行バナー
画面最上部には、大会全体のリアルタイム動態が表示されます。
* 🔴 **試合中（Live）**: 現在コートに入場して試合を行っているチーム数。
* 🟡 **待機中（Waiting）**: 次、またはその次に控えている招集待ちチーム数。

### 1.2 状態フィルターチップ
* 【すべて】【試合中のみ】【待機中のみ】のチップをタップして、いま熱戦を繰り広げているチームだけを素早く絞り込めます。

### 1.3 部門・コートの切り替え
* 上部のタブバー（「小学生の部」「中学生男子」など）をタップするか、**画面を左右にスワイプ** することで部門やコートを瞬時に切り替えられます。

---

## 2. チーム進捗カードの見方と操作 {#team-card}

一覧に並ぶ各チームカードには、応援に必要な最新情報が集約されています。

* **チーム名・ステータスバッジ**:
  - 🔴 試合中、🟡 待機中、⚪ 終了
* **対戦カード情報**:
  - 現在のコート名（例: 第2コート）
  - 対戦相手のチーム名
  - 試合順（例: 準決勝 第1試合）
  - **現在進行中のポジション**: （例: 「中堅戦進行中」）
* **タップで詳細へ直行**:
  - チームカードをタップすると、団体戦の場合は **「団体戦スコアボード（先鋒〜大将の星取表）」**、個人戦の場合は **「リアルタイム試合速報画面」** へ直接ジャンプします。
* ※ 観客席画面では、運営用のBAND編集ボタンや管理メニューは安全のため自動的に非表示（情報保護仕様）となっています。
