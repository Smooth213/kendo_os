# 観客用チーム試合状況

保護者や応援の方々が、**「我が子のチームや所属道場が、いま第何試合場で戦っているか」「次はいつ出番なのか」** を客席やロビーから素早く確認できる画面です。

## 1. チーム試合状況の見方 {#how-to-view}

- **🔴 試合中（Live）**:
  - 現在コートに入場して試合を行っているチームです。タップすると該当コートのライブ速報画面へ直行できます。
- **🟡 待機中（Waiting）**:
  - これから試合を控えているチームです。次に招集されるチームや、あと何試合で出番かが分かります。
- **⚪ 終了（Finished）**:
  - 本日の試合をすべて終えたチームです。

## 2. 便利な機能 {#features}

- **フィルター機能**:
  - 【試合中のみ】を選ぶと、いま熱戦を繰り広げているチームだけを一覧表示できます。
- **部門・コートの切り替え**:
  - 画面を左右にスワイプするか、上部のタブをタップして「小学生」「中学生」「第1試合場」などを簡単に切り替えられます。
- **ドックからの呼び出し**:
  - どの画面からでも右下のドックボタンから「🥋 チーム状況」を1タップで展開できます。
