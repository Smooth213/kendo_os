# 観客用公式戦記録（全試合結果）

大会で行われたすべての試合（団体戦・個人戦・勝ち抜き戦・リーグ戦）の確定スコアテーブルを、客席や自宅から公式記録として閲覧できる画面です。

## 1. 画面の見方と特徴 {#features}

- **対戦別スコアテーブルカード**:
  - 先鋒から大将までの選手氏名、取得した一本（面、小手、胴、突き、反則、判定）、取得本数が表形式で正確に表示されます。
  - 勝敗がついたチームには「勝」マークが点灯します。
- **部門別タブ切り替え**:
  - 画面上部のタブから、「小学生低学年」「中学生男子」などの部門を個別に選んで結果を振り返ることができます。

## 2. ☀️ 高コントラスト出力ボタン {#high-contrast-mode}

画面右上の **【☀️ 高コントラスト】** ボタンをタップすると、画面の配色が純白と漆黒（最高コントラスト比21:1）に切り替わります。
体育館の窓際や屋外の直射日光下、またはスマートフォンの画面が反射して見づらい環境でも、文字がくっきりと見やすくなります。

## 3. 安心・公平のための情報保護規約 {#parity-security}

観客用公式戦記録画面では、未確定の試合結果の漏洩や誤解を防ぐため、**「確定した公式記録のみ」** がリアルタイムで反映されます。
また、本部の内部集計用サマリーなどは表示されず、公認された公式スコアのみが美しく提示されます。
