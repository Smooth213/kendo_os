# 観客用部内戦スコア確認

道場の稽古日や月例会で行われている「部内戦」のスコア、勝敗、本日の順位ランキングを、保護者や見学者がスマホでリアルタイムに確認できる画面です。

## 1. 画面の見方 {#features}

- **本日の部内戦タイムライン**:
  - 個人戦、紅白戦（団体戦）、総当たりリーグ戦、勝ち残り無限戦の対戦結果が時系列で流れます。
- **本日のリーダーボード（ランキング）**:
  - 本日の稽古で誰が多く勝ち星を挙げたか、取得本数が何本かなどの上位ランキングが表示されます。
- **過去の部内戦記録の閲覧**:
  - カレンダーから過去の日付を選ぶことで、先月や前回の部内戦の記録もいつでも振り返ることができます。
