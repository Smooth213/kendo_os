# 勝ち抜き戦スコアボードの見方

玉竜旗（ぎょくりゅうき）や魁星旗などの勝ち抜き方式（抜き勝負）において、「現在の連勝数（〇人抜き）」「両チームの残り選手数」「勝敗の推移」をリアルタイムに確認できる専用スコアボードです。

## 1. 画面の見方 {#viewer-kachinuki-view}

- **現在コート上の対戦者**: 現在戦っている両チームの選手名、取得本数が大きく表示されます。
- **連勝数（〇人抜きバッジ）**: 勝った選手が何人連続で相手を倒しているかが鮮やかにバッジ表示されます（例: 「3人抜き！」）。
- **控え選手スロット**:
  - **白く点灯**: これからコートに立つ控え選手
  - **暗い表示（消灯）**: すでに敗戦、または引き分けで退場した選手
- **残り選手数**: 両チームの残り人数がカウント表示されます。

## 2. 勝ち抜き戦の勝敗ルール {#viewer-kachinuki-rule}

1. **基本ルール**:
   - 試合の勝者はそのままコートに残り、相手チームの次の選手と対戦します。
   - 途中のポジションで引き分けた場合、原則として **両者退場（両選手とも敗退）** となり、両チームとも次の選手が出場します。
2. **大将同士の対決（決着ルール）**:
   - 両チームとも大将（最後の1人）まで進んだ場合、引き分けはなくなり、勝敗が決するまで **「時間無制限の一本勝負（延長戦）」** が行われます。
3. **チームの勝利**:
   - 相手チームの大将を先に倒したチームが完全勝利となります。
