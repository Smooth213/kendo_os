# 勝ち抜き戦スコアボードの見方

玉竜旗（ぎょくりゅうき）や魁星旗などの勝ち抜き方式（抜き勝負）において、「現在の連勝数（〇人抜き）」「両チームの残り選手数」「控えスロットの点滅」「勝敗の推移」を客席からリアルタイムに確認できる専用スコアボードです。

---

## 1. 画面構成と表示要素 {#viewer-kachinuki-view}

### 1.1 コート上の対戦者
* 現在戦っている赤・白両チームの選手氏名、取得技ランプ（【メ】【コ】【ド】【ツ】【反】）、秒単位の試合タイマーが表示されます。

### 1.2 連勝数（〇人抜きバッジ）
* 勝ち残っている選手が相手を何人倒したかが、画面上に目立つ **「〇人抜き！」バッジ** としてハイライト表示されます（例: 「3人抜き！」）。

### 1.3 控え選手スロットインジケータ
* **白く点灯**: これから出番を迎える控え選手。
* **消灯（グレーアウト）**: すでに敗戦、または引き分け退場となった選手。
* 両チームの残り選手数（例: `残り 3人 vs 残り 1人`）が一目で分かります。

---

## 2. 勝ち抜き戦の公式ルールと決着 {#viewer-kachinuki-rule}

本システムは伝統的な勝ち抜き戦公式ルールに完全準拠しています。

1. **勝者残留**:
   - 試合に勝った選手はそのままコートに残り、相手チームの次の選手と続けて対戦します。
2. **引き分け時の両者退場（ダブルノックアウト）**:
   - 先鋒〜副将の対戦で引き分け（時間切れ・勝負つかず）となった場合、原則として **両者退場（両選手とも敗退）** となり、両チームとも次の控え選手が出場します。
3. **大将同士の対決（時間無制限一本勝負）**:
   - 両チームとも大将（最後の1人）まで到達した場合、引き分けルールは消滅し、どちらかが一本を取るまで終わらない **「時間無制限一本勝負（延長）」** に自動移行します。
4. **チームの完全勝利**:
   - 相手チームの大将を先に倒し、全選手を退場させたチームが勝者となります。
