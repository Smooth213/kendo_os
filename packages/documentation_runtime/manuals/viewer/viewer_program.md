# 大会プログラム閲覧・個人メモ

大会の進行表、トーナメント表、会場図などのPDFや画像をスマホで閲覧し、自分専用の手書きメモを書き込める高機能ビューワーです。紙のプログラムを持ち歩く必要がありません。

---

## 1. プログラムの開き方と直交ナビゲーション {#how-to-open}

* **開き方**:
  - 画面右下のフローティングドックボタン、または観客ホームから【📄 プログラム】をタップします。
* **縦スクロール（ページめくり）**:
  - PDFの複数ページを上下スクロールでなめらかにめくることができます。
* **横スワイプ（ファイル間切り替え）**:
  - 別のトーナメント表や進行表（例: 午前の部 ➔ 午後の部）へ、左右スワイプで瞬時に切り替えられます。
* **ピンチズーム排他制御（誤スワイプロック）**:
  - 2本指で画面を広げて、細かなトーナメントの山や文字を大きく拡大できます。
  - **拡大中（ズーム倍率 > 1.01）は左右スワイプが自動的に完全ロック** されるため、文字を追ったりメモを書いている最中に画面が勝手に切り替わってしまうストレスはありません。

---

## 2. 観客向け手書きアノテーションツールバー {#drawing-tools}

画面上部のペンアイコン（✏️）をタップすると、手書き描画ツールバーが展開されます。

### 2.1 自分専用の個人ペン（青・黒）
* **完全プライベートな手書きメモ**:
  - 個人ペンで書いた線は、**手元の端末内（Isar DB）にのみ保存** されます。
  - 他の観客や運営本部には一切共有・公開されません。勝敗予想や「〇〇君が勝った！」などの個人的なメモを自由に書き込めます。

### 2.2 🖍️ 蛍光マーカー（半透明・乗算合成）
* 下のトーナメント文字や罫線を塗りつぶさずに、自分の子どもや応援チームの対戦枠を鮮やかにハイライトできます。

### 2.3 📢 大会本部からの共有ペン（ピンク・イエロー）の自動表示
* 大会本部が書き込んだ「試合場の変更」「最新の勝ち上がり赤線」「重要連絡」が、**手元のスマホにリアルタイムで自動同期・表示** されます。
* **保護ガード**:
  - 観客端末からは本部の共有ペンを誤って消去できないよう保護されているため、常に正確な公式情報を受け取れます。

### 2.4 🧹 消しゴム ＆ ↩️ Undo
* 自分が書いた個人メモの線だけをピンポイントで消去したり、直前の1手を元に戻せます。

---

## 3. PDFテキスト全文検索 {#pdf-search}

画面上部の虫眼鏡アイコン（🔍）をタップすると、PDFテキスト検索バーが展開されます。

* **選手名・所属学校名の検索**:
  - 探したい選手名を入力すると、該当箇所がリアルタイムに黄色でハイライトされます。
* **次へ / 前へ移動**:
  - マッチした件数が表示され、矢印ボタンで次の試合枠へ瞬時にジャンプできます。
