# 大会プログラム閲覧・個人メモ

大会の進行表、トーナメント表、会場図などのPDFや画像をスマホで閲覧し、自分専用の手書きメモを書き込める高機能ビューワーです。紙のプログラムを持ち歩く必要がありません。

## 1. プログラムの開き方と操作 {#how-to-open}

- **開き方**: 画面右下のドックボタン、または観客ホームから【📄 プログラム】をタップします。
- **縦スクロール（ページめくり）**: PDFの複数ページを上下スクロールでなめらかに閲覧できます。
- **横スワイプ（ファイル切り替え）**: 別のトーナメント表や進行表へ左右スワイプで切り替えられます。
- **ピンチズーム（拡大・縮小）**: 2本指で画面を広げて、細かなトーナメントの文字をくっきり拡大できます。拡大中は横スワイプが自動停止するため、文字を追っている最中に画面が勝手に切り替わる心配はありません。

## 2. 観客向けの手書きアノテーション機能 {#personal-memo}

画面上のペンアイコンをタップすると、手書きメモツールバーが利用できます。

1. **個人ペン（青・黒）**:
   - **自分だけにしか見えない手書きメモ** です。
   - 勝敗予想や「〇〇君が勝った」などのメモを自由に書き込めます。他の観客や運営本部には一切見えません。
2. **蛍光ペン（半透明）**:
   - 自分の子どもや所属チームの対戦箇所に蛍光ラインを引いて目立たせることができます。
3. **本部からの共有指示（ピンク・黄色）の閲覧**:
   - 大会本部が書き込んだ「試合場の変更」「最新の勝ち上がりライン」などの重要情報が、**手元のスマホにリアルタイムで自動表示** されます。
   - ※観客側から本部の共有指示を消去することはできないため、安全に正確な情報を受け取れます。
4. **個別消しゴム / Undo**:
   - 自分で書いた個人ペンの線だけを消しゴムや取り消しボタンで消去できます。
