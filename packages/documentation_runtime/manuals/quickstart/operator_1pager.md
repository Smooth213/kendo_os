# 🏛️ 大会本部・審判長 机上クイックガイド（机上ラミネート用）

**大会本部席・審判長席で大会全体の進行統括、ルール変更、緊急アナウンス、結果出力を最短操作で行うための要約ガイドです。**
* 引率・運営 ログインPIN: **`1111`**
* 大会管理者 ログインPIN: **`2222`**

---

## 🛠️ 大会本部の4大主要業務フロー

### 1. 進行管理と急遽コート振替
* **大会ホーム画面** で全コート（第1〜第N試合場）のリアルタイム進行と残り試合数を確認。
* 進行が遅れているコートがある場合、試合カードをドラッグまたはメニューから別コートへ振替（第105条規約によりリアルタイム同期）。

### 2. 一括ルール変更（時間短縮・延長無制限）
* 会場退出時間や審判スケジュールが逼迫した場合、ドックまたは設定から **【一括ルール変更】** を開きます。
* 「全コート対象」「後半の対戦のみ」などを選び、試合時間（3分 ➔ 2分）や延長判定条件をワンタップで一括適用できます。

### 3. 本部一斉アナウンス ＆ 本部共有ペン
* **緊急連絡ポップアップ**:
  - 本部から「選手招集」「審判打ち合わせ」「落とし物連絡」を投稿すると、館内の全端末（記録員・観客席）へ一斉ポップアップ表示。
* **本部共有ペン（ピンク・イエロー）**:
  - トーナメント表に勝ち上がり赤線やコート変更メモを書き込むと、Firestore経由で全参加者の端末へリアルタイム同期（観客側からの消去は保護ガード）。

### 4. 成績管理と公式出力（PDF / LINE）
* 大会終了後、**「成績管理（公式記録）」** を開きます。
* **PDF出力**: 日本剣道連盟公式書式A4組版で印刷・PDF保存。
* **LINE画像出力**: LINEグリーン（#06C755）の美しい画像で保護者・関係者へ即座に共有。
* **遠征成績サマリー**: 個人技別内訳や勝率をワンタップでLINE用整形テキストとしてコピー。

## 🚨 トラブル発生時の本部指示
1. **記録机で通信が切れた場合**:
   - 記録員へ「そのまま点数入力を継続してください」と指示（IsarローカルDBがデータを完全保護）。
2. **審判合議によるスコア訂正**:
   - 当該試合のスコアボードを開き、手動修正またはUndoで補正（すべての修正は第203条監査ログに安全記録）。
3. **重大なデータ疑義時**:
   - 「運用ダッシュボード（Observability）」でエラー率・遅延・CRDT整合性を確認。
