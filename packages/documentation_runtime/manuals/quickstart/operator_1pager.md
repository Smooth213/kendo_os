# ⏱️ 記録係 クイックガイド（机上用マニュアル）

**「説明書なしで3分で使える」現場特化型ガイドです。システムが万が一止まっても、大会（試合）は絶対に止めないでください。**

---

## 🛠️ 現場での4大基本操作ステップ

### 🏗️ ステップ 1: 試合作成 (Match Setup)
大会ホーム画面の右上にある「➕ 試合を追加」ボタンをタップします。
カテゴリー（例: 小学生の部、一般の部）と、対戦する赤・白のチーム名または選手名を入力するだけで、10秒で試合がセットアップされます。
`!試合作成画面UI`

### 🥋 ステップ 2: スコア入力 (Score Input / 一本・反則)
主審の「始め」の合図で **【試合開始】** ボタンを押し、タイマーを起動します。
有効打突（一本）が決まったら、取った側の **【面 (M)】【小手 (K)】【胴 (D)】【突き (T)】** ボタンをタップします。
反則が発生した場合は、該当する側の **【反則▲】** ボタンを押してください（自動で累積カウントされ、2回で相手に一本が自動付与されます）。
`!スコア入力画面UI`

### 📱 ステップ 3: Viewer共有 (Viewer Share / 観客席連携)
客席の保護者や、遠方の関係者にリアルタイム速報を共有するには、画面内の **【観客席にURLを共有】** ボタンを1タップします。
URLがクリップボードに自動コピーされると同時に、LINEやSNSへ一発で転送できます。また、スマホ掲示用の入場QRコードも自動発行されます。
`!Viewer共有画面UI`

### 📄 ステップ 4: PDF出力 (PDF/CSV Export / 大会結果)
全試合が終了したら、画面最下部の **【確定】ボタンを「長押し」** して試合を承認します。
公式記録画面から **【PDF形式で出力】** または **【CSV形式で出力】** ボタンを押すと、A4印刷に最適化された美しい対戦スコア詳細がその場で書き出され、そのまま全員に配布可能です。
`!PDF出力画面UI`

## ↩️ 間違えたら？（Undo・取り消し操作）
- 押し間違えや、審判の「取り消し」がかかった時は、焦らずに **【↩️ Undo（取り消し）】** ボタンを押してください。
- 100回連続まで安全に過去の歴史を巻き戻すことができます。データの整合性は裏側で完全に自動保護されています。
