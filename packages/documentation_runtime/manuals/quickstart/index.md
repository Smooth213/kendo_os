# ⏱️ クイックガイド

現場で「とにかくこれだけ見れば今すぐ動かせる」ための、役割別1枚要約ガイドです。
大会当日の机上にラミネート配置してご活用ください。

---

## 役割別 机上1枚ガイド
- 🏃 **[大会開始まで3分の超特急ガイド](3min_setup.md)**: 役割選択から大会入場、試合開始、確定までの最短3分マニュアル
- 📋 **[記録係 机上クイックガイド（机上用）](recorder_1pager.md)**: 記録机・計時席専用シート（PIN: 9999、タイマー赤点灯、一本、Undo、確定、ドック）
- 🏛️ **[大会本部・審判長 机上クイックガイド（机上用）](operator_1pager.md)**: 大会本部・審判席専用シート（PIN: 1111/2222、コート進行、一括ルール変更、本部アナウンス、共有ペン）
- 📱 **[観客・保護者用 1枚ガイド（スマホ観戦シート）](viewer_1pager.md)**: 保護者・選手向けのスマホ閲覧ガイド（QR入場、見方、ドック、LINE共有）
