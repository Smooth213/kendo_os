# ⏱️ Kendo Sync (kendo_os) タイマー精度および時間同期ポリシー

本アプリにおける試合時間タイマーは、全日本剣道連盟規則に則った正確なスコアプロジェクションを行うための補助表示システムであり、以下の時間管理ポリシーに基づいて設計されています。

## 🛑 1. 本アプリは「公式時計」ではありません
- 剣道大会における公式な残り時間の計測、および試合終了（タイムアップ）の最終的な合図は、常に各コートの時計係が手動で操作するストップウォッチやブザー（物理時計）を絶対のマスター（主時計）として運用してください。
- アプリ上のタイマーは、本部や客席へ進行状況の目安を伝えるための「参考表示」として位置付けられています。

## 📶 2. Viewer（客席・遠隔閲覧）における通信遅延の許容
- 客席のスマートフォン（Viewer画面）に表示される残り時間は、操作員の入力端末（配信元）のクロックをマスターとして同期されます。
- 打突一本の発生時や一時停止（Stop/Start）の瞬間にミリ秒単位のパケットで同期されますが、体育館内部の劣悪なネットワーク遅延（ラグ）により、客席側の秒表示が操作元と1〜3秒程度前後する場合があります。これはシステム異常ではなく、分散ネットワークにおける許容された仕様設計です。

## 🔒 3. 決定論的リプレイ（TimeSourceの一元化）
- 本アプリ内のすべてのタイマー再計算ロジックは、直接の `DateTime.now()` への依存を100%排除し、抽象化された `TimeSource` を経由して稼働しています。
- これにより、バックグラウンドスリープ等によって端末の時計が不連続にスキップした場合でも、内部で蓄積された経過時間（ランポート論理時計等）と完全に照合され、データの不整合や巻き戻りバグを数学的に100%防止します。
