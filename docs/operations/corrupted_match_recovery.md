# 🛠️ 試合データ破損時（問題発生バナー表示時）の手動復旧・救済マニュアル

大会現場において、電波の極端なズレや端末の異常フリーズにより、試合画面の上部に **「データに問題が発生しました」** という赤いバナーが表示された場合の復旧オペレーション手順です。

## 🚨 1. 発生する現象（症状）
- 該当する試合の新規スコア入力、およびタイマー操作が安全のためにロックされます。
- 客席の閲覧画面（Viewer）は、その時点までのスコアを表示したままフリーズせず維持されます。

## 🛠️ 2. 本部スタッフによる復旧手順（リカバリ・ドリル）
1. **端末の再同期（リロード）**
   - 画面右上の「戻るボタン」で一度大会ホームに戻り、再度該当の試合をタップして開き直してください。
   - バックグラウンドの `rebuildMatchSnapshot` プロトコルが自動起動し、過去の有効な打突イベント履歴（Event Sourcing）から、一瞬で正しい試合状態（スコア・タイマー）を再演算して100%復元します。

2. **「履歴から復元」ボタンによる手動救済**
   - 状態が戻らない場合は、画面内の「履歴から復元」ボタンをタップします。
   - 記録されている有効な履歴の一覧（1本目、2本目…）が表示されますので、問題が起きる直前の正常だったポイントの版数を選択し、「確定」を押すことで、不整合データをスキップして安全な歴史までジャンプバックできます。

3. **Event Export（生データのテキスト救済）**
   - 上記の手順でも復旧しない深刻な破損の場合、ドメイン層の `allowExport` 権限が自動付与されます。
   - 画面から生イベントログ（CSV/TXT）をテキスト出力し、本部で試合結果を紙媒体へ書き写して大会進行を継続してください。アプリが原因で大会進行がストップすることは絶対にありません。
