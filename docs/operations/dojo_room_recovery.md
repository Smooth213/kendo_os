# 🛡️ Stage2 β 現場緊急データ復旧・リカバリー手順書

剣道の試合会場（体育館）において、通信混雑による同期遅延や、複数端末からの同時誤操作によってデータが暴走・硬直した場合の、本部席における公式リカバリープロトコルを以下に定義する。

## 1. 現象：特定の端末だけスコア同期がフリーズした場合
* **原因**: ブラウザの IndexedDB / LocalStorage の内部キャッシュスタックが、通信瞬断時に一時的なデッドロックを起こしている可能性。
* **処置**: 
  1. アプリを完全に一度閉じ、ブラウザの「再読み込み（リロード）」を実行。
  2. それでも復旧しない場合は、PWAを一度ホーム画面から削除し、再度Safari/Chromeから「ホーム画面に追加」を執行する。
  3. フェーズ3で構築した `localStorage` ハイブリッド復元機構により、再起動後も直前の道場スペース（organizationId）へ全自動で再接続・再同期が執行される。

## 2. 現象：誤って途中の試合データを全削除・初期化してしまった場合
* **原因**: 現場の操作員によるタップ事故、または再確認PINの突破ミス。
* **処置**:
  1. 本部席の最高管理者（Admin: 9999）の端末から、「システム設定（SettingsScreen）」へ進入する。
  2. フェーズ2で定義した `organizations/{dojoId}/auditLogs` の直近の履歴を確認。
  3. 各試合ドキュメントの内部に保存されている「イベント駆動打突履歴（`timeline` / `events`）」を、最古のものから順番に `KendoRuleEngine.rebuildMatchFromEvents()` へ再投入することで、誤消去された試合のスコア、残り時間、勝敗状態を0ミリ秒で完全巻き戻し・100%現物復旧させることができる。

## 3. 現象：一般保護者端末（Viewer）に本部画面が露出、またはその逆の権限崩壊
* **原因**: URL直打ちによるパラメータ偽装、またはブラウザセッションの破損。
* **処置**:
  1. 不正端末を即座に回収し、URLをクリーンな `/viewer/{organizationId}` に強制書き換えする。
  2. `RouteGuard`（STEP 6-1）の自動水際ブロックが発火し、セッションは強制的に最安全な `UserRole.viewer` へ降格・隔離される。
  3. その後、本部席のデバイスからのみ、正しい管理者PIN「9999」を入力してセッションを特権へと再昇格させる。
