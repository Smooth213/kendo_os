# 👁️ Stage2 β 現在機能露出一覧定義書

本ドキュメントは、一般の道場、保護者、錬成会で利用されるプロダクトとして、露出させる機能と完全に隠蔽する内部システムを確定・固定するものです。

## 🟢 一般ユーザーに見せる機能（露出スコープ）
- **Viewer (観客・保護者用画面)**: リアルタイム一本速報・ドロープログラム閲覧
- **スコア入力**: 試合の記録、メ・コ・ド等の打突・反則入力
- **Undo**: 連打防止ガード付きの履歴1手取り消し機能
- **タイムライン**: 団体戦・個人戦の進行状況アコーディオン
- **公式記録**: PDF出力およびCSVダウンロード
- **ローカル保存**: Isarによる1〜3秒以内のライトスルー即時永続化
- **Viewer共有**: QRコードおよびURLによる観客席への配信
- **クイックマニュアル**: 3分超特急ガイドおよび簡易FAQ

## 🔴 完全に隠蔽する内部機能（非表示スコープ）
- **Governance Runtime**: 憲法バリデーター、Replay検証
- **Replay管理**: 状態再生ダッシュボード、Drift解析
- **AI Runtime**: 判定サジェスト、AIレビューヘルパー
- **Rule DSL**: ルール構成編集パネル、外部DSLインポート
- **Observability**: 内部メトリクス監視ダッシュボード、監査ログ
- **Multi Operator**: 複数操作員による衝突判定
- **Capability System**: 実行権限検証 Runtime
