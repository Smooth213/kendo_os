# 🛑 Known Limitations (既知の制限事項)

Kendo Sync (kendo_os) Stage 2 β版をご利用いただくにあたり、以下の制限事項および免責事項をご確認ください。

## ⚠️ 重要な免責事項 (Disclaimers)

1. **正式大会公式記録用途ではありません**
   本システムは現在ベータ版として提供されており、データの永続性や完全性を法的・公式に保証するものではありません。各連盟や大会主催者の定める公式記録用紙（紙媒体）との併用を強く推奨します。

2. **タイマーは補助表示です**
   画面上に表示される試合タイマーは、ネットワークの通信ラグや端末の処理遅延による影響を受ける可能性があります。客席のViewer（閲覧専用）画面へは、打突一本の発生時やタイマーのStart/Stop時にミリ秒単位で同期されますが、公式な時間管理・試合終了の合図には、必ず現場の時計係が操作するストップウォッチ等を使用してください。

3. **審判判定補助AIではありません（AI機能の完全封鎖）**
   本システムは、記録係によって入力されたイベント（打突や反則）の履歴に基づいてスコアや勝敗を計算・表示する、純粋な記録管理システムです。打突の有効性（一本）や反則を映像や音声からAIが自動判定・補助する機能は一切有していません。一般公開されるStage2 β環境においては、UI導線、サービスランタイム、マニュアルの文脈にいたるまでAIモジュールは100%完全に遮断・封鎖されています。最終的な判定はすべて人間の審判員に委ねられます。
