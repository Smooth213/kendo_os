# ❄️ Stage2 β 同期ストリーム構造・フリーズ（凍結）宣言書

## 1. 宣言の目的
本ドキュメントは、自動テスト241件を完全パスした現行の安定版 `kendo_os` を道場戦・錬成会の実戦配備に投入するにあたり、運用中のインフラ崩壊・先祖返りを防ぐためのデータ構造変更禁止を厳格に宣言するものである。

## 2. 厳禁事項（凍結対象）
身内テスト・道場運用の期間中、以下の変更をリポジトリに加えることを一切禁止する。

* **Firestore構造の変更**: `organizations/{dojoId}/...` の階層およびコレクション名（`matches`, `players` 等）の改名、ネスト位置の変更。
* **ドメインモデルの破壊**: `MatchModel`, `TournamentModel` などのコアエンティティにおける必須フィールド（`organizationId` 等）の削除・型変更。
* **認証PIN・ロールの追加**: `UserRole`（admin, operator, recorder, viewer）に存在しない、新しい中間の特権（例: `sub_operator` など）の無断追加。

## 3. 解凍基準
本凍結の解除は、Stage2 βテストが完全終了し、道場・保護者・運営者からのフィードバックがすべてアセット化され、Stage3（正式大会対応版）のインフラ設計へ移行するタイミングまで、一切認められない。
