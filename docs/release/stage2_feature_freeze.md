# ❄️ Stage2 β Feature Freeze 宣言仕様書

本仕様書は、kendo_os Stage2 β版の現場投入における絶対的な安定性を担保するため、新規機能拡張の凍結を宣言するものです。

## 🚫 厳格禁止事項
1. **新機能の追加禁止**: 大会運営・試合記録に直接関係のない新規ロジックの追加を一切禁止します。
2. **UI・画面の追加禁止**: 一般ユーザー向け、開発者向けを問わず、新たな画面コンポーネントの追加を禁止します。
3. **Rule DSLの拡張禁止**: ルールエンジンのパーサー、インタプリタ、および新しい構文規則の追加を凍結します。
4. **AI機能の公開禁止**: 自動判定補助を含むすべての AI Runtime への外部導線の追加を禁止します。
5. **Governance機能の公開禁止**: Constitutionalチェック、Replayの変更ログ、監査画面の露出を一切禁止します。
